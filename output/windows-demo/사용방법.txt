UniversityPath Windows x64 시연 설치기

1. UniversityPath-Demo-Setup.exe를 시연 PC로 복사해 더블클릭합니다.
2. [설치 / 실행]을 누릅니다. 처음에는 인터넷, Windows 권한 승인과 Docker 약관 동의가 필요할 수 있습니다.
3. 재부팅 안내가 나오면 Windows를 재부팅하고 같은 EXE를 다시 실행합니다.
4. 준비되면 http://localhost:38100이 열립니다. [시연 계정 보기]에서 새 학생/관리자 계정을 확인합니다.
5. [시연 종료]를 눌러도 시연 중 저장한 데이터는 유지됩니다.

학교 기준과 선택한 수강·요건 체크가 포함됩니다. 원래 계정의 비밀번호·세션·AI 인증 정보는 포함하지 않습니다.
자료 메뉴의 기기 PDF/설명은 이 묶음에 포함되지 않습니다. 외부 AI 기능은 별도 연결/설정이 필요합니다.
Windows x64·RAM 8GB 이상·하드웨어 가상화가 필요합니다. BIOS 가상화가 꺼져 있거나 관리 정책으로 WSL/Docker 설치가 막히면 중단합니다.
이 EXE는 코드 서명이 없는 시연용 파일입니다. 함께 제공한 SHA-256 체크섬으로 파일 손상을 확인할 수 있습니다.
현재 파일은 소유자가 실제 수강·체크 데이터를 포함한 공개 배포를 승인한 시연 묶음입니다.

현재 Docker가 있는 개발 PC에서는 실제 복원·학생/관리자 로그인·재실행 보존을 검증했습니다.
Docker가 없는 새 PC에서의 최초 설치·UAC·재부팅은 별도 실기 확인이 필요합니다.
