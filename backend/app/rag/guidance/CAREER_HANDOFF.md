# 취업 분석 메뉴 전달서

2026-11-06. 프론트·백엔드 코드와 기존 HTTP API는 변경하지 않았다.
AI 모듈은 `../career/`, 메뉴 예시는 `examples/career-responses.json`에 있다.

## 클릭 흐름

처음 → **취업 분석** → 다음 중 선택:

| node_id | 버튼 | 다음 화면에 필요한 값 |
|---|---|---|
| career:recommend | 내 자료로 공고 찾기 | 선택 기록, 사용자가 선택한 직무·지역 |
| career:profile | 내 자격증·경험 분석 | 선택 기록 |
| career:posting | 공고 1개와 비교 | 선택 기록, 공고 본문 |
| career:sources | 공고 수집처 안내 | 없음 |

분석 메뉴 클릭은 `needs_input`을 반환한다. 클릭 자체로 자료를 보내거나 유료 모델을 호출하지 않는다.
`workflow`와 `integration_state`는 새 표현 필드다. 기존 프론트가 처리한다고 가정하지 않는다.

권장 화면: 자료 선택 → 직무·지역 직접 선택 → 외부 분석에 사용할 자료 확인 →
공고 후보 카드 → 요구사항별 근거 비교. 개인 요약은 별도의 선택 단계로 제공한다.
LLM이 사용자의 직무·지역을 자동 확정하거나 검색 조건을 몰래 바꾸지 않는다.

## 카드 표시

공고 제목 / 회사 / 지역 / 수집처 / 마감 안내 / 수집 시각 / 원 공고 링크를 표시한다.
본문에 비교 결과를 보여주고, 링크만 나열하는 화면으로 끝내지 않는다.
다만 현재 공식 검색 API는 요약 정보이므로 상세 조건이 없으면 **상세 근거 부족**을 표시한다.
`comparisons`에는 필수·우대, 비교 상태, 공고 인용, 내 기록 인용과 설명이 있다.
`source_order` 결과를 적합도 순위 또는 합격 확률로 표시하면 안 된다.

- `analysis_status=completed`: 근거 비교 결과 표시.
- `insufficient_evidence`: 비교할 요구사항 근거가 부족함.
- `personal_analysis_not_authorized`: 개인 분석 요청 필요.
- `not_configured`: 운영 연결 준비 중.
- `failed`: 분석 실패, 공고 정보는 유지.
- `budget_exhausted`: 이번 분석 한도에 도달, 후속 분석 동작은 서버 계약 필요.
- `warnings`: 요약 정보 한계와 마감 확인 안내를 함께 표시.

## 담당자별 연결할 일

**백엔드**

기존 개인 컨텍스트 조립·소유권 검증 및 공고 1개 분석 API는 재사용 가능하다.
2026-11-07에 `EvidenceAnalyzer`를 공고 1개 분석 API에 연결했다. 공고 인용은 공고에 있는 문구면
허용하고 반복되면 아직 쓰지 않은 위치에 연결한다. 키가 없어 실제 Vertex 호출은 검증하지 않았다.
여러 사이트 검색 및 개인 요약의 공개 API는 새 합의가 필요하다. 내부 서비스 응답을
프론트용 Pydantic/OpenAPI 계약으로 확정하고 인증·요청 제한·예외/취소·버전 재검사를 적용한다.
사람인/고용24 키, 지역 코드 매핑, Vertex 프로젝트·리전·정확한 모델 ID·ADC를 설정한다.
잡코리아는 이용 승인 후 전용 주소·명세를 확보해야 구현을 마무리할 수 있다.

**프론트**

메뉴의 workflow를 자료 선택 폼으로 연결한다. 직무와 지역은 필수 사용자 선택이며,
전국은 명시적 옵션이다. 사이트별 지역 코드를 사용자에게 직접 입력하게 하지 않는다.
검색/분석/부분 실패/자료 부족을 각각 표시한다. 기존 개인 자료 선택 UI와
새 다중 공고 카드 UI를 연결한다. 포트폴리오 파일 업로드 기능은 아직 없다.

**AI/RAG 및 QA**

키·명세가 제공되면 실제 응답으로 어댑터를 확인하고 모델의 인용 정확도·의미적 타당성을 평가한다.
프론트 QA는 별도로 만든 자격증/경험/공고로 검토한다. 개발 테스트에서 쓰지 않은 문구를 사용하고,
정상 비교, 자격증 미기재, 우대/필수 구별, 근거 없는 주장, 마감 공고, 일부 사이트 실패,
시간 초과, 자료 미선택, 다른 사용자 자료 접근 차단을 확인한다.

## 현재 완료와 미완료

완료: 정적 메뉴, 두 사이트 공식 API 어댑터, 공통 공고 구조, 조건 검증,
선택 자료 분석기·근거 검증, Vertex JSON 어댑터, 오프라인 테스트.

미완료: 실 인증키/모델 호출 검증, 잡코리아 실 수집, 공고 상세 본문 자동 확보,
운영용 지역 코드 카탈로그, 공개 API·프론트 연결, 파일 포트폴리오 추출.
이 문서는 합의/연동 작업 목록이며 운영 기능이 이미 켜져 있다는 의미가 아니다.
