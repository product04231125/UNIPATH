# 공통 스타일 비교

- Pretendard와 기존 글자 크기 체계를 유지한다. 입력·버튼·카드·대화상자의 기본 모서리는 20px다.
- 네 팔레트: 크림·브라운(기본), 밝은 파랑, 다크 퍼플, 다크 오렌지. 배경·본문·보조 글자·강조·선택·테두리를 공통 ColorScheme으로 연결한다.
- 밝은 강조색의 버튼 글자는 대비에 따라 흰색 또는 검정으로 조정한다. 상태와 일정 분류 색은 의미를 유지하며 상태 배지는 어두운 배경에 맞춘다.
- 개발 빌드의 팔레트 버튼은 현재 세션에서만 전체 테마를 전환한다. 작성 중 입력·현재 경로·역할·합성 데이터는 유지한다. Release에는 비교 버튼을 표시하지 않는다.
- 현재 기본값은 비교 시작점이며 최종 브랜드 색을 확정한 사용자 설정이나 서버 계약이 아니다. 분리된 채팅 창은 창마다 독립적으로 비교한다.
- 로그인·회원가입·기록·관리 폼 전체에 고정 라벨과 개별 입력창을 사용한다. 인증·저장 기능은 기존 목업 경계를 유지한다.
- 공통 드롭다운은 20px 목록 표면·얇은 경계·8px 안쪽 여백과 가벼운 그림자를 사용한다. 선택 항목은 체크와 옅은 선택 배경으로, 호버/키보드 포커스는 별도 반응으로 표시한다. 기존 위치 보정·포커스 복귀를 유지한다.
- 버튼은 공통 배경/호버/눌림 반응과 키보드 포커스 윤곽을 제공한다. 호버 그림자 대신 색 변화로 표시한다. 채팅 선호 복원은 복원 아이콘을 가진 보조 버튼이다. 관리자 상세는 중립 테두리/이동 아이콘, 수정은 옅은 강조 배경/편집 아이콘으로 구별한다.
- 개발 비교 패널에서 삭제의 붉은 테두리·옅은 붉은 배경·채워진 붉은 배경을 전환한다. 초기값은 옅은 붉은 배경이다. 다크 삭제는 선명한 붉은색을 사용하고 기본/호버 글자 대비·확인/취소 흐름을 검증한다. 선택은 세션 동안만 유지한다.
- 같은 비교 패널에서 관리자 기존 1열/반응형 2열을 선택한다. 설정 배치 비교는 최신 사용자 결정에 따라 제거했다. 현재 시안은 체크로 표시하며 패널은 좁은 화면에서 스크롤한다. 레이아웃의 기본값은 반응형 2열이고 공간·글자 확대가 허용하지 않으면 1열로 쌓는다. 전환/창 크기 변경 중 입력과 포커스를 보존한다. Release에는 비교 조작을 노출하지 않는다.

- 대상: 공통 버튼 식별성/색 호버, 상세·수정 구분, 다크 삭제 3종 비교, 설정 폭/2문단, 학교·학과 1·2열 비교. 채팅 헤더/제목표시줄·파일 기반 포트폴리오·새 설정 옵션은 포함하지 않는다.
