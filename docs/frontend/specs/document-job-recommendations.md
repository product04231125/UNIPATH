# 내 자료로 공고 찾기

## 사용자 흐름

학생이 채용공고 분석에서 ‘내 자료로 공고 찾기’를 연다. 기존 공고 본문 분석은 별도 흐름으로 유지한다. 직무와 지역을 직접 선택하고 기기의 파일 또는 본인 저장 기록을 고른다. 파일명·선택 기록과 외부 처리 고지를 확인한 뒤 분석 실행을 누른다. 선택한 자료에서 추출한 텍스트를 Google Gemini로 보내는 데 동의한 경우에만 요청한다.

입력·자료 선택 → 외부 전송 확인 → 처리 중 → 추천 목록 또는 빈 이유 → 공고별 비교·자료 인용 펼치기 순서다. 오류 뒤 직무·지역·파일·기록 선택을 보존한다. 처리 중 중복 실행을 막으며 자동 재전송하지 않는다. 계정 교체·로그아웃 시 선택과 결과를 폐기한다. 게스트는 전송하지 않는다.

## 계약과 경계

- PR #69의 `backend/app/rag/career/api.py`, `FRONTEND_HANDOFF.md`, 응답 JSON이 연결 근거다. 기본 OpenAPI 파일에는 새 경로가 없으므로 기존 단건 응답 모델을 확장하지 않는다.
- `POST /api/v1/me/job-recommendations`: 직무·지역, 파일 바이트의 base64, 선택 기록 종류·ID·버전, 외부 처리 동의, 최대 3건.
- 기기 파일 5개·합계 8MiB, PDF·DOCX·UTF-8 TXT/MD·PNG/JPEG/WebP. PDF 쪽수·OCR 장수·추출 조각 수는 서버에서 검증한다. 기기 자료를 자동 수집하거나 파일 보관함을 만들지 않는다.
- 공급자별 공식 지역 코드 카탈로그가 없어 최초 연결은 명시적 ‘전국’만 활성화한다. 지역 선택란과 제한 사유를 표시하며 코드를 추정하거나 사용자에게 코드 입력을 요구하지 않는다.
- 서버 순서대로 추천을 표시한다. 미확인 필수조건 수·공고와 개인 자료 인용·파일명·쪽수·OCR 표시를 제공한다. 합격 확률이나 프런트 계산 점수를 만들지 않는다.
- 추천 0건에서도 비교 대상과 수집처별 상태를 표시한다. 수집 실패·모델 실패·근거 부족·설정 필요를 구분한다.

## 화면 방향과 검증

기존 FeaturePage·SurfaceCard·테마·외부 링크 확인을 재사용한다. 데스크톱 입력, 처리 중, 부분 성공, 추천 없음, OCR 출처, 오류 후 입력 보존을 합성 응답으로 검증한다. 로컬 실제 API 확인은 경로와 연결 상태까지만 수행한다. 실제 OCR·모델·공고 수집의 실행 결과나 품질을 검증했다고 보고하지 않는다.
