# 학교별 학사 안내 자료의 관리자 연결 — 계약 요청안

- 상태: 2026-11-08 사용자 방향 반영. **현재 공개 API가 아닌 후속 계약 요청안**이다. 백엔드·관리자 연결 UI·실제 학교별 활성화는 미구현이다.
- 목적: 프런트 빌드에 학교 UUID를 넣지 않고, 관리자가 등록 학교와 안내 자료 묶음을 연결한다. 학생은 본인 설정의 등록 학교에 연결된 안내를 읽는다.
- PR #52의 고정 수집본을 모든 학교에 동일하게 제공하지 않는다. 개인 기준 사용자의 PDF 질문과는 별도 기능이다.

## 관리자 화면의 목표 동작

기존 관리자 `학교` 상세에 `학사 안내 자료` 구역을 둔다. 학교가 선택되지 않으면 먼저 학교 선택을 안내한다.

1. 현재 연결된 자료 묶음의 이름·판본·자료 학교/출처·수집 시각·상태를 조회한다.
2. 서버가 제공하는 사용 가능한 자료 묶음 목록에서 고른다. 출처 학교와 공식 사이트를 확인할 수 있게 표시한다.
3. 연결·교체를 명시적으로 저장한다. 연결 해제는 대상·학생 안내에 미치는 영향을 확인한 뒤 수행한다.
4. 저장 성공 후 서버 상태를 재조회한다. 저장 실패·409 버전 충돌은 선택을 유지하고 재확인을 제공한다. 저장 후 재조회만 실패하면 저장을 반복하지 않는다.

권한 기본안은 기존 관리자 학교 범위를 따른다. 슈퍼관리자는 전체, 학교관리자는 허용된 학교만 관리하며 **서버가 최종 검증**해야 한다. 프런트에서 임의 UUID 입력·학교 이름 추정·로컬 설정 저장으로 연결을 대체하지 않는다.

## 백엔드/AI 계약 의존성

정확한 경로·필드명·오류 코드는 담당자가 OpenAPI로 확정한다. 아래는 프런트가 연결할 기능과 필요한 정보다.

| 기능 | 입력 | 필요한 응답·검증 |
| --- | --- | --- |
| 연결 가능한 안내 자료 목록 | 관리 대상 등록 학교, 목록 cursor | 자료 묶음 ID·이름·판본·출처 학교/URL·수집 시각·이용 가능 상태·다음 cursor |
| 학교의 현재 연결 조회 | 등록 학교 UUID | 연결 없음/연결됨/이용 불가, 연결된 묶음 메타데이터, 동시 수정용 버전 |
| 연결·교체 | 학교 UUID, 선택 자료 묶음 ID/판본, 예상 연결 버전 | 관리 범위·자료 이용 가능 여부·잘못된 학교/자료 조합·버전 충돌 검증, 저장된 연결 |
| 연결 해제 | 학교 UUID, 예상 연결 버전 | 권한·동시 수정 검증, 해제 후 상태 |
| 학생용 안내 지원 상태 조회 | 저장된 등록 학교 UUID | 해당 학교 연결 여부·조회 가능 여부·자료 묶음 판본, 안내 노드 조회에 사용할 문맥 |
| 학생 노드·원문 조회 | 등록 학교 문맥 + 서버가 준 node/asset ID, 선택한 본인 audit ID | 현재 학교의 유효한 연결만 조회. 다른 학교 자료·해제된 연결·과거 판본 혼용 방지 |

- 1차 대상은 서버에 이미 수집된 안내 자료 묶음이다. 이 명세에서 새 PDF 업로드·추출·색인 파이프라인을 요구하지 않는다.
- 자료 연결은 메뉴형 참고 안내를 선택하는 행위다. 학교 문서 RAG 승인·공식 졸업 판정 기준·학생 기록 승인 상태를 변경하지 않는다.
- 기존 `GET /me/academic-guidance/nodes/{node_id}`와 asset API에는 현재 학교 선택 인자가 없다. 연결 정보를 저장하는 API뿐 아니라 학생 조회가 그 연결을 실제 사용하도록 하는 계약도 필요하다.
- 연결 해제·자료 판본 변경 뒤 기존 노드/원문 ID를 재사용할 때의 동작을 정의해야 한다. 프런트는 기존 화면을 지우고 연결 상태·첫 메뉴를 다시 조회할 수 있어야 한다.
- 파일 제공·자료 소유/공개 범위·학교 대응 검증·연결 저장·감사 기록은 백엔드/AI 담당 범위다.

## 학생 화면과 현재 경계

- 현재 채팅의 학사 안내 메뉴·카드·OCR 경고·표·공식 감사 선택·원문 보기는 구현돼 있다.
- 2026-11-08 사용자 수정 요구로 관리자 연결 계약 유무에 따른 진입 차단을 해제했다. 제품 `학교 질문`은 서버 트리 메뉴를 바로 조회하며, 등록 학교 연결이 미확인인 서버 수집 참고 자료라는 안내를 표시한다.
- 학교 UUID를 넣는 빌드 설정을 최종 연동 방법으로 사용하지 않는다. 테스트의 확인된 학교 주입은 합성 fixture 검증을 위한 내부 경계이며 실제 관리자 연결을 뜻하지 않는다.
- 계약 확정 후 학생 프로필 UUID로 연결 상태를 조회해 메뉴 안에서 실제 연결/미연결을 안내한다. 연결된 자료 선택은 서버 계약을 따르며, 진입 자체를 막는 고정 UUID 가드로 되돌리지 않는다.

## 계약 확정 후 검증할 시나리오

- 허용 학교 연결·교체·해제, 범위 밖 학교 차단, 이용 불가 자료 차단.
- 409와 저장 후 재조회 실패에서 입력 보존·중복 저장 방지.
- 연결 없음/해제/판본 변경 시 학생의 안내·원문 재조회와 이전 자료 표시 방지.
- 학교 A의 node/asset을 학교 B 문맥으로 조회할 수 없음.
- 자료 연결이 RAG 승인·졸업 판정 결과를 변경하지 않음.

이 문서는 새 프런트 Draft PR에서 검토를 요청할 계약 초안이다. 기존 PR #52 댓글이나 담당자 개인 메시지는 수정·전송하지 않는다.
