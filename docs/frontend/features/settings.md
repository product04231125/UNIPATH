# 설정

## 목적

설정은 목록의 필터·정렬·기록 추가가 아니라 드물게 바꾸는 개인화·AI·접근성·계정 옵션을 위한
독립 본문 페이지다.

## 현재 구현

- `frontend/lib/features/settings/settings_page.dart`에 좌측 탐색 하단의 설정 진입 화면이 있다.
- 실제 제어 없이 준비 중 상태만 보여 준다.

## 목업 경계

- 계정, 학교·학과 기준, AI 대화 이력, 접근성, 알림, 내보내기·삭제 요청은 아직 구현하지
  않았다.
- 비밀번호·토큰·외부 API 키는 화면에 입력·표시하지 않는다.

## 후속 계약·검증

- 설정 항목은 API·권한·영구 저장 정책이 확정된 뒤에만 노출한다.
- 메뉴 전환과 사용 불가 상태의 이유 표시를 위젯 테스트한다.
