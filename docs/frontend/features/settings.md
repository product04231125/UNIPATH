# 설정

## 목적

설정은 목록의 필터·정렬·기록 추가가 아니라 드물게 바꾸는 개인화·AI·접근성·계정 옵션을 위한
독립 본문 페이지다.

## 현재 구현

- 정상·읽기 실패 본문 모두 공통 스크롤 컨테이너로 입력 카드와 스크롤바를 16px 분리한다.
- Windows에서 `채팅창 열기 방식`을 분리 창(기본) / 내부 패널로 선택한다. 저장 성공 뒤에만
  값을 바꾸고 다음 열기부터 적용한다. 현재 열린 창을 옮기거나 AI를 자동으로 열지 않는다.
  최대화 중에는 내부 패널을 사용한다. Web에는 네이티브 창 설정을 노출하지 않는다.
- 채팅 설정 읽기 실패는 원본을 보존하고 쓰기를 막으며 다시 읽기를 제공한다. 저장 실패는
  기존 값을 유지한다. 기본값 복원은 채팅 열기 방식만 바꾸고 다른 데이터는 삭제하지 않는다.

### 설정 소유권과 적용 범위

| 항목 | 소유권·저장 | 플랫폼·적용 | 초기화 범위 |
| --- | --- | --- | --- |
| 학교·학과·입학연도·계획 학년·주 시작 요일 | 개인 계획 repository, 기기 로컬 | Web/Windows, 명시적 저장 뒤 | 이번 작업에서 삭제·전체 초기화 미제공 |
| 채팅 열기 방식 | `ChatPreferences`, 별도 기기 로컬 v1 키 | Windows, 다음 열기부터 | 이 항목만 분리 창 기본값으로 복원 |
| 테마·글꼴·글자 확대 | 기존 시스템/앱 테마 | 플랫폼 설정을 따름 | 별도 조작·초기화 제어 미제공 |
| 계정·알림·대화 보존·동기화·내보내기/삭제 | API/권한 계약 미확정 | 동작 없는 제어를 노출하지 않음 | 정책 미확정, 이번 범위에서 정의하지 않음 |

- 공통 `PageHeader`에서 한글 `설정` 제목 아래 `일반` 문맥을 표시한다. 기존 960px 최대 폭과
  왼쪽 시작선, 설정 입력·저장 흐름은 유지하며 읽기 대기·실패에도 제목을 표시한다.
- 본문은 작업 공간의 왼쪽 시작선에 맞추고 최대 폭 960을 사용한다. 학년·주 시작 요일은 공통
  anchored 선택 제어로 열며 선택·Esc 이후 키보드 포커스를 원래 제어에 돌려준다.

- `일반 > 학업과 계획`에서 학교, 학과, 입학연도, 개인 계획 학년을 입력한다.
- 입학연도와 현재 3월 기준 학년 시작 시점을 사용해 1–4학년 개인 계획 값을 제안하며, 사용자가
  직접 덮어쓸 수 있다.
- 홈의 7일 표와 일정의 월간 달력 요일은 기본 일요일부터 시작하며, 사용자가 주 시작 요일을
  바꿀 수 있다.
- 이 값과 일정은 현재 기기의 로컬 저장소에만 저장한다. 공식 학적, 학교 데이터, 졸업 판정이나
  서버 추천을 변경하지 않는다.
- 저장이 성공한 뒤에만 프로필과 성공 표시를 갱신한다. 실패하면 작성 값을 유지하고 같은
  화면에서 재시도할 수 있다. 성공 뒤 다시 수정하면 성공 표시를 지운다.
- 저장소 읽기 실패는 빈 프로필로 대체하지 않는다. 쓰기를 차단하고 원본 보존·재시도를
  표시하며, 최초 읽기 재시도가 성공하면 복구된 프로필을 입력란에 표시한다.

## 목업 경계

- 계정, AI 대화 이력, 접근성, 알림, 내보내기·삭제 요청은 아직 구현하지 않았다.
- 비밀번호·토큰·외부 API 키는 화면에 입력·표시하지 않는다.

## 후속 계약·검증

- 동기화 API가 정해지면 로컬 저장소 어댑터를 API repository로 교체하고 마이그레이션·삭제 정책을
  함께 정한다.
- 로컬 저장, 자동/직접 학년 선택, 메뉴 전환을 위젯 테스트한다.
- `chat_preferences_test.dart`: 기본값·재시작·복원 격리·읽기/쓰기 실패, 창 host를 통한
  분리/도킹·최대화·재사용·닫은 뒤 재열기·실패 대체와 200% 좁은 설정 제어를 검사한다.
  실제 Windows 창 위치·전면화·DPI는 이 위젯 검사로 검증했다고 간주하지 않는다.
- `planning_storage_test.dart`: 저장 실패/예외의 프로필·일정·원본 보존, 잘못된 저장 데이터의
  쓰기 차단과 복구, 설정 입력 보존·재시도·성공 표시 초기화, 홈·일정·설정의 읽기 재시도를 검사한다.

## 공통 선택 팝업 점검

- 설정 학년·주 시작 요일, 일정 분류, 기록 입력·필터, 포트폴리오 종류·공개 범위 선택은
  모두 `AnchoredSelectField`를 사용한다. 별도 Dropdown/PopupMenu 경로는 현재 소스에 없다.
- `workspace_ux_test.dart`에서 트리거 아래 위치, 가장자리 보정, Enter로 재열기,
  선택·Esc 후 정확히 해당 트리거 FocusNode로 복귀하는지 검사한다.
- Windows/Linux 플랫폼 설정의 관련 4개 검사 통과(테스트 명령 1회). 제품 코드는 변경하지
  않아 이전 홈 카드 단위의 Web·Windows 빌드를 재사용한다. 사용자 최종 확인으로 팝업 점검을
  마무리했다. Esc는 자동 검사된 보조 키보드 동작이며 별도 필수 수동 확인으로 요구하지 않는다.
  메뉴·하위 탭의 제목·본문 시작선과 보조 문구는 팝업 점검과 별개인 공통 헤더 정책을 따른다.
