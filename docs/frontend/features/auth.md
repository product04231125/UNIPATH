# 인증과 계정

일반 로그인·회원가입은 실제 FastAPI 계정·세션 API에 연결한다. 계약과 최초 운영자
생성은 [인증 API](../../api/authentication.md), 정확한 DTO는 [OpenAPI](../../api/openapi.json)를 따른다.

- 기존 테마·폼·비밀번호 표시를 유지한다. 가입 비밀번호는 15~128자, 이름은 최대 128자다.
  중복 제출/모드 변경을 막고 실패 시 입력·오류 안내·재시도 경로를 유지한다.
- Web은 HttpOnly 쿠키, Windows는 프로세스 메모리 토큰을 사용한다. 비밀번호·토큰을
  SharedPreferences에 저장하지 않는다. 로그아웃은 서버 세션을 종료한 뒤 화면을 전환하며
  통신 실패 시 로그인 상태를 유지한다.
- 역할은 서버 응답의 user/school_admin/super_admin으로 결정한다. 실제 관리자는 DB의
  학교 범위 화면을 사용한다. 합성 학사 편집기는 개발 샘플 진입 전용이며 Release에는 없다.
- 클라이언트는 60초 간격/앱 복귀 시 신원을 갱신하고, 서버는 매 요청 현재 권한을 확인한다.
  만료 401이면 로그인으로 돌아가되 통신 실패만으로 세션을 폐기하지 않는다.
- 실제 일반 계정의 학업 프로필·일정은 서버 저장이며 다른 개인 자료는 사용자 UUID별 기기 저장소로 분리한다. 기존 익명 자료를 자동 귀속하지 않는다. 본인 기기 프로필·일정 이전은 동의 후 진행하며 다른 개인 자료 서버 전환·이메일 검증/복구·SSO는 후속 작업이다.

검증은 auth_integration_test.dart의 실제 HTTP 계약·토큰 비영속성·입력 보존·중복 제출·
서버 관리자 역할 진입·계정별 자료 격리 및 기존 탐색/기록/설정 테스트를 사용한다.
