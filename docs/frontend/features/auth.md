# 인증 목업

## 목적

학생과 관리자가 목업 작업 공간에 진입하거나 회원가입 입력 흐름을 확인한다. 실제 인증·권한·토큰을
대신하지 않는다.

## 현재 구현

- 공통 Pretendard·20px 모서리와 설정에서 선택한 3개 제품 테마를 적용한다. 로그인·회원가입 모두 고정 라벨이 있는 개별 입력창을 사용한다. 입력 오류·비밀번호 표시·기존 진입 역할은 유지한다.
- 화면 목업 로고·인증 미연결 안내·역할 구현 예정 문구는 제거했다. 회원가입 제출 버튼은 `회원가입`으로 표시한다. 개발용 샘플 진입 영역과 기존 Release 노출 조건은 유지한다. 문구 변경이 실제 인증·계정 생성 구현을 의미하지는 않는다.
- `frontend/lib/features/auth/login_page.dart`에 로그인·회원가입 전환과 기본 입력 검증이 있다.
- 로그인 성공은 앱의 로컬 상태를 작업 공간 진입 상태로 바꾼다. 작업 공간의 사용자 영역에서
  로그아웃하면 같은 로컬 상태를 끝내고 로그인 화면으로 돌아간다.

## 목업 경계

- 계정 조회, 비밀번호 검증, 서버 세션·역할 판정, 로그아웃 서버 호출은 구현하지 않았다.
- 입력값은 실제 사용자 계정이나 인증 계약이 아니다.
- 개발 빌드의 샘플 영역은 왼쪽 학생, 오른쪽 학교관리자·슈퍼관리자로 나뉜다.
  샘플 버튼은 Release 빌드에 노출하지 않는다. 일반 로그인은 기존 학생 목업이며 실제
  관리자 역할은 인증 응답으로 연결할 예정이다. 관리자 샘플은 공통 관리자 작업 공간으로 진입한다.

## 후속 계약·검증

- 2026-10-15 문구 정리: 관련 7개 테스트 파일의 127개 사례 확인. 최초 126개 통과 후 제거된 회원가입 안내를 기대하던 1개를 수정해 해당 사례만 재실행·통과했다(테스트 명령 2회). 분석 1회, Web·Windows 빌드 각 1회 통과. 문구·배지 정리이며 실제 인증·서버 저장 계약은 기존 미연결 상태다. 이번 변경의 별도 실기 화면 검사는 수행하지 않았으며 좁은 폭·확대는 관련 위젯 검사로 확인했다.

- OpenAPI에 역할·인증·세션 종료 계약이 생긴 뒤 학생/학교 관리자 권한을 서버 기준으로
  연결한다.
- 로그인 검증, 회원가입 전환, 로그아웃 흐름을 위젯 테스트한다.
