# 인증 목업

## 목적

학생이 목업 작업 공간에 진입하거나 회원가입 입력 흐름을 확인한다. 실제 인증·권한·토큰을
대신하지 않는다.

## 현재 구현

- `frontend/lib/features/auth/login_page.dart`에 로그인·회원가입 전환과 기본 입력 검증이 있다.
- 로그인 성공은 앱의 로컬 상태를 작업 공간 진입 상태로 바꾼다. 작업 공간의 사용자 영역에서
  로그아웃하면 같은 로컬 상태를 끝내고 로그인 화면으로 돌아간다.

## 목업 경계

- 계정 조회, 비밀번호 검증, 세션, 역할, 로그아웃 서버 호출은 구현하지 않았다.
- 입력값은 실제 사용자 계정이나 인증 계약이 아니다.

## 후속 계약·검증

- OpenAPI에 역할·인증·세션 종료 계약이 생긴 뒤 학생/학교 관리자 권한을 서버 기준으로
  연결한다.
- 로그인 검증, 회원가입 전환, 로그아웃 흐름을 위젯 테스트한다.
