# 외부 링크 열기

## 현재 구현

- 활동의 `1365 봉사 찾기`는 목업 스위치와 학교 연동 여부에 관계없이 사용할 수 있다.
- 자격의 `Q-Net에서 확인`도 같은 확인·외부 열기·복사 제어를 사용한다.
  Q-Net API 조회·자격 취득 확인·보유 내역 동기화가 아니다.
- 개인 자격·성과·교육과정·규칙의 증빙/출처 URL은 기록 옆 `외부 열기`로 열 수 있다.
  fixture 링크를 개인 근거나 공식 인증으로 취급하지 않는다.
- `external_link_button.dart`는 목적지와 새 탭/기본 브라우저 이동을 표시하고 사용자 확인을 받는다.
  취소하면 아무것도 열지 않는다. 열기는 확인 버튼 클릭에서 바로 플랫폼 어댑터를 호출한다.
- 반환 실패·예외는 대화상자 안에 재시도와 링크 복사를 제공한다. 복사 실패 시 URL을 직접 선택할 수 있다.
  브라우저의 새 탭 차단 또는 외부 사이트 로딩 성공을 클라이언트가 모두 감지할 수 있는 것은 아니다.
- `external_links.dart`는 `http/https` 및 호스트를 검사하고, 로그인 정보·공백·제어문자·역슬래시와
  `file/javascript/mailto` 등 비브라우저 주소를 거부한다. 저장 입력과 열기가 같은 검증을 사용한다.
  이전 저장 데이터의 잘못된 URL도 열기·복사를 비활성화한다.

## 플랫폼과 경계

- Web: `_blank` 새 탭 요청. Windows: 외부 애플리케이션 모드로 기본 브라우저 요청.
  [url_launcher 공식 문서](https://pub.dev/packages/url_launcher)의 API를 사용한다.
- 외부 열기 성공은 봉사 신청, 학교 승인, 자격 인증, 제출·공개 완료 또는 근거 검증을 뜻하지 않는다.
  1365 로그인·데이터 교환·시간 가져오기·서버 전송과 파일 업로드는 구현하지 않는다.
- 포트폴리오의 구성·로컬 사용 의도·지원 문서는 [포트폴리오 기능](portfolio.md)에서 관리한다.
  외부 링크를 열어도 이 초안이나 실제 공개·제출 상태를 바꾸지 않는다.

## 검증

### Q-Net 링크 보완

- `external_links_test.dart --name "Q-Net"`: 2개 통과(1회). 학교·목업·AI 의존 없이 표시,
  확인 전 플랫폼 미호출, 취소, 확인 후 외부 브라우저 요청, 자격 원본 보존,
  1440×900 및 480×520·200% 글자 확대를 검사한다.
- 분석·Web·Windows 빌드는 각각 1회 성공. 공통 링크 제어는 바꾸지 않아 기존 77개
  전체 검사 결과를 재사용하고 전체 테스트를 반복하지 않았다.

### 공통 링크 제어 구현 당시 검증

- `external_links_test.dart` 10개: 플랫폼 호출 모드/새 탭, 안전한 URL, 확인·취소,
  성공/반환 실패/예외, 링크 복사, 잘못된 기존 URL, 목업 없이 1365 표시,
  성과 링크, 480×520·200% 글자 확대.
- 기존 전체 테스트에서 48개 통과 후 새 테스트 파일 10개 통과. 테스트 명령 총 4회:
  최초 관련 테스트 → 전체 검사(새 테스트 어댑터 컴파일 실패) → 관련 파일 수정·재검사 실패
  → import 수정 후 관련 파일 통과. 기존 전체 테스트는 반복하지 않았다.
- `flutter analyze`: 테스트 어댑터·중괄호 수정 후 문제 없음(2회). Web·Windows 빌드는 각각 1회 성공.
- 실제 Windows 기본 브라우저 호출과 Web 새 탭 차단 환경의 수동 실행 확인은 하지 않았다.
