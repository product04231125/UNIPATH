# 활동

## 목적

교내 활동·봉사·동아리·공모전을 활동 단위로 관리한다. 개인 기록과 학교 승인 기록을 혼동하지
않는다.

## 현재 구현

- 전체 기록 목록의 세로 스크롤바와 카드는 16px 분리한다. 내부 병렬 카드의 중첩 스크롤은 제거했다.

- 전체 기록 종류(개인 졸업 입력 포함)는 공통 입력 모달을 사용한다. 빈 신규 입력은 바깥 클릭으로
  닫히며 작성 내용·수정 기록은 명시적 취소로만 버린다. 본문 스크롤과 16px 스크롤바 여백,
  항상 접근 가능한 저장·취소 영역을 공유한다.

- 활동과 다른 기록 메뉴는 같은 행의 목록·준비 카드를 공통 `EqualHeightRow`로 정렬한다.
  760px 미만에서는 자연 높이의 세로 배치이며, 기록·긴 문구·글자 확대도 고정 높이로 자르지 않는다.

- 공통 `PageHeader`로 한글 제목·설명을 표시하며 중복 영어 라벨은 제거했다.
  읽기 대기·실패에도 제목을 유지하고 학교 미연결·개인 기록 안내는 보존한다.
- `frontend/lib/features/records/activity/activity_page.dart`가 화면·입력 상태를 소유한다.
- 예시 행은 `frontend/lib/features/records/fixtures/activity_fixture.dart`에 있다.
- 기관·기간·역할·직접 입력 봉사 시간·사용자가 확인한 승인 시간/상태/확인일을 분리 입력한다.
  개인 기록 CRUD와 기기 로컬 저장, 사용자가 승인됨으로 기록한 봉사 시간 합계를 제공한다.
  상세 경계는 [ERD 대조](../manual-input-boundaries.md)를 따른다.
- `1365 봉사 찾기`로 외부 포털을 확인 후 열거나 링크를 복사한다. 목업·학교 연동 없이도
  사용 가능하며 개인 기록과 승인 상태는 바꾸지 않는다. [외부 링크](external-links.md)를 따른다.

## 목업 경계

- 현재 직접 입력은 개인 보조 기록이며 학교 승인, 졸업 반영, 외부 활동 인증을 뜻하지 않는다.
- 1365 등 외부 서비스와의 데이터 교환·인증·저장은 구현하지 않는다.

## 후속 계약·검증

- 공통 모달 회귀는 전체 기록 종류의 빈 폼/공백 바깥 클릭, 내용 보호, 기존 수정값을
  비운 뒤에도 유지되는 보호를 검사한다. 초기 입력 검사에서 카드 변경 시 높이 재측정 누락을
  발견해 수정했으며 기존 기록 CRUD/개인 졸업/성과 검사와 동적 높이 검사가 통과했다.

- `card_layout_test.dart`는 전체 기록 종류의 빈/긴 기록, 글자 배율 1/2에서 병렬 카드 경계를 검사한다.
  홈 기존 카드 검사와 일정의 병렬/세로 배치 검사를 함께 실행해 관련 10개가 통과했다.

- 제목, 기관/유형, 기간·시간, 역할, 증빙, 출처·승인 상태의 계약을 확정한다.
- 직접 입력이 활동 메뉴에만 반영되는지 위젯 테스트한다.
