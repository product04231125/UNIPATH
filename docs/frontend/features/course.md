# 수강 관리

## 목적

학교 수강 기록을 확인하고 현재·다음 학기 계획을 정리한다. 지원되지 않는 학교의 사용자는
개인 기준을 위한 보조 기록을 직접 입력할 수 있다.

## 현재 구현

- `frontend/lib/features/records/course/course_page.dart`가 화면과 직접 입력 상태를 소유한다.
- 예시 행은 `frontend/lib/features/records/fixtures/course_fixture.dart`에 분리돼 있다.
- 목업용 스위치는 예시 행만 숨기며, 이번 실행에서 직접 추가한 행은 유지한다.

## 목업 경계

- 과목명·학점·학기 등 현재 입력과 예시 행은 API 모델이나 학교 확정 수강 기록이 아니다.
- 교육과정 행렬, 학기 필터, 학점 합계, 삭제·수정 정책은 아직 계약되지 않았다.

## 후속 계약·검증

- 공식 수강 기록과 개인 보조 기록의 출처·수정 가능 여부를 API에서 구분한다.
- 직접 입력이 수강 메뉴에만 반영되는지 위젯 테스트한다.
