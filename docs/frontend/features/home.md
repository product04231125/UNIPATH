# 홈

## 목적

홈은 통계 대시보드보다 학생이 다음 작업을 고르는 시작 화면이다. 졸업 가능 여부를 단정하거나
AI 대화를 강요하지 않는다.

## 현재 구현

- `frontend/lib/features/home/home_page.dart`에 홈과 빠른 이동 카드가 있다.
- `학사 기준`, `이번 학기와 활동`, `공식 문서`, `성과와 진로` 카드가 관련 메뉴 이동을 요청한다.

## 목업 경계

- 카드의 상태·안내는 실제 학교 연동, 졸업 판정, 공식 문서 연결을 뜻하지 않는다.
- 학교 연동 부재 시 안내와 첫 기록 입력 흐름은 API·개인 기준 계약 뒤 확정한다.

## 후속 계약·검증

- 빠른 이동 목적지와 카드 디자인을 기능 변경 때 함께 검증한다.
- 카드가 개인 기준을 학교 공식 판정으로 표시하지 않는지 확인한다.
