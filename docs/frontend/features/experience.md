# 경험

## 목적

프로젝트·인턴·스터디·동아리 경험을 개인의 사실 기반 기록으로 관리한다.

## 현재 구현

- 공통 `PageHeader`로 한글 제목·설명을 표시하며 중복 영어 라벨은 제거했다.
  읽기 대기·실패에도 제목을 유지하고 학교 미연결·개인 기록 안내는 보존한다.
- `frontend/lib/features/records/experience/experience_page.dart`가 화면·입력 상태를 소유한다.
- 예시 행은 `frontend/lib/features/records/fixtures/experience_fixture.dart`에 있다.
- 종류·기관·기간·역할·결과/개인 기여·진행 상태를 분리 입력하며 개인 기록을 추가·수정·삭제한다.
  실제 계정은 서버에서 재조회하며 debug/이전 원본은 기기에 남는다. [ERD 대조](../manual-input-boundaries.md)를 따른다.

## 목업 경계

- 실제 계정의 서버 저장을 연결했다. 증빙 파일 업로드·별도 임시저장·이탈 경고는 후속이다.
- AI는 후속 계약 전 경험 원본을 저장하거나 확정하지 않는다.

## 후속 계약·검증

- 상황/과제, 역할, 실행, 결과·배운 점, 기간, 증빙의 입력 계약을 확정한다.
- 직접 입력의 메뉴 내 반영을 위젯 테스트한다.

## 2026-10-14 작성 내용 취소 보호

명시적 취소 시 신규 작성 내용 또는 원본 대비 변경이 있으면 폐기 확인을 표시한다.
계속 작성은 입력과 선택을 보존하고, 내용 폐기만 닫는다. 빈 신규·무변경 수정은 확인 없이
취소한다. 저장 중 차단과 저장 실패 입력 보존은 유지한다. 공통 구현과 검증 범위는
[공통 입력 검증](../verification/ux-ui-verification.md)을 따른다.

## 2026-10-14 가독성 개편

- 개인 기록을 먼저 표시하고 예시 행은 뒤에 둔다. 별도 목업 안내 문구를 제거했으며 개인 기록/합계에는 포함하지 않는다. 준비 안내는 목록 아래 접는 영역으로 제공한다.
- 관련 기록/작업 공간 회귀 41개와 활동 예시 분리 신규 검사 통과. 최종 검증은 [1·2·4 검증 기록](../verification/ux-124-verification.md)을 따른다.
