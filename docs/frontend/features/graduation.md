# 졸업 요건과 개인 기준

## 목적

졸업요건 화면은 서버 또는 개인 기준 계산이 전달한 결과를 읽기 쉽게 표시하고, 사용자가 개인
기준 입력 화면으로 이동·편집할 수 있게 한다. 판정과 근거를 만들거나 선택하지는 않는다.

## 현재 구현

- `frontend/lib/features/graduation/graduation_page.dart`에 졸업요건 화면, 탭, 개인 기준 설정
  다이얼로그와 로컬 상태가 있다.
- 예시 표 행은 `graduation_mock_fixture.dart`에 분리돼 있다.

## 목업 경계

- 현재 표 행과 개인 기준 상태는 화면 흐름 검증용 fixture·로컬 상태이며, 공식 졸업감사나
  학교 규정이 아니다.
- UI는 받은 결과가 개인 기준임을 표시할 수 있지만, 공식/개인 여부나 충족 여부를 스스로
  계산·추론하지 않는다.

## 후속 계약·검증

- OpenAPI 계약이 생기면 화면에 필요한 표시 상태와 사용자 입력만 연결한다. 요청·응답 필드,
  판정 의미, 근거 선택은 프론트엔드 문서에서 정의하지 않는다.
- 개인 기준 항목 추가·저장, 받은 결과의 공식/개인 표시 구분을 위젯 테스트한다.

## 화면 밖 책임

적용 규칙 선택, 졸업 충족 판정, 공식 문서 근거 검색은 Flutter가 아닌 서버 도메인의 책임이다.
그 책임과 데이터 흐름은 [시스템 아키텍처](../../architecture-erd.md)를 기준으로 한다.
