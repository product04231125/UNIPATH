# 졸업 요건과 개인 학업 작업 공간

## 교육과정 행렬의 탐색 전환

- `내 교육과정` 예시 행렬은 구분 열 92px, 나머지 열 최소 58px 및 카드 여백·테두리를
  포함한 최소 폭을 작업 공간에 전달한다. 현재 15열에서 필요한 본문 폭은 942px이다.
- 펼친 메뉴와 AI 도킹 때문에 이 폭이 부족하면 메뉴를 먼저 아이콘으로 접는다. 그 뒤에도
  부족할 때만 행렬의 공통 헤더·행 컨테이너에 가로 스크롤바를 표시한다.
- 다른 기준 탭·개인 기준 작업 공간·다른 메뉴로 이동하거나 목업 표를 숨기면 이 요구를
  해제한다. 창을 넓히거나 AI를 닫아 공간이 확보되면 메뉴를 복원한다.

## 현재 구현

- `graduation_page.dart`는 API 미연결 상태를 명시하고 기존 졸업 표를 예시로만 표시한다.
  목업 스위치를 끄면 예시 표 대신 미연결 안내를 표시한다.
- `내 학교·학과 기준 설정`에서 교육과정 → 교육과정 과목 → 개인 규칙을 관리한다.
  세 목록은 별도 로컬 키에 저장하며 추가·수정·확인 후 삭제와 재진입·재시작 보존을 제공한다.
- 교육과정: 이름, 개인 학교·학과, 입학연도, 교육과정 연도, 메모·출처 URL.
  설정의 학업과 계획 프로필과 별개인 교육과정별 적용 범위이며 프로필 수정으로 규칙을 초기화하지 않는다.
- 과목: 이름·코드·학점·이수구분·개인 필수 여부, 개인 교육과정과 선택적 수강 기록 연결.
- 규칙: 이름·코드·종류·개인 적용 범위, 필요한 값·직접 확인한 현재 값·단위,
  조건/대체 요건/성적 기준 설명, 적용 시작·종료일, 출처 URL.
  개인 교육과정, 선택적 교육과정 과목, 수강·활동·경험·자격·성과 기록을 연결한다.
- 관계는 목록에서 고른 기기 로컬 UUID이며 서버 FK로 취급하지 않는다. 규칙과 연결 과목의
  교육과정이 다르면 저장을 거부한다. 삭제는 연쇄 삭제가 아니며 남은 참조는 `연결 대상 없음`으로
  표시하고 수정 시 재선택·연결 해제를 요구한다. 연결 내용은 재선택할 때까지 그대로 보존한다.
- 연도 형식, 양의 학점, 음수·비유한 값, 실제 날짜·적용 기간, 안전한 URL을 검증한다.
  저장 성공 뒤만 목록을 바꾸고, 실패 시 작성 값·기존 저장 내용을 보존한다.
- 개인 교육과정·규칙의 출처 URL은 확인 뒤 외부 열기·복사를 제공한다.
  링크를 여는 것은 공식 근거 검증이나 졸업 판정이 아니다. [외부 링크](external-links.md)를 따른다.

## 목업·API 경계

- 개인 자료는 공식 학교·교육과정·규칙 마스터가 아니다. 서버 전송·파일 업로드·RAG 등록을 하지 않는다.
- 현재 값과 조건은 사용자가 기록한 내용이며 규칙을 실행하는 표현식이나 서버 enum이 아니다.
  Flutter는 충족·미충족을 계산하지 않는다. 기존 화면 내부 숫자 비교 목업은 제거했다.
- 졸업 판정·개인 계산은 서버 Rule Engine 책임이다. 판정 API가 없으므로 현재 규칙 입력 화면에는
  계산 결과가 없다. 공식 표의 예시 결과는 개인 입력으로 변경되지 않는다.

## 후속 계약·검증

- 서버 규칙 타입·조건 스키마, 개인/공식 구분, 비교 연산·성적 환산, 다중 기록 연결,
  버전·감사 이력, 설정 프로필 매핑, 동기화·병합·삭제 이력은 OpenAPI 합의가 필요하다.
- `personal_graduation_test.dart`: 세 목록의 CRUD·재마운트, 수정 시 다른 목록 보존,
  교육과정 불일치·삭제된 참조, 입력 검증, 480×520·200% 글자 확대를 검사한다.
  `personal_records_test.dart`의 저장소 검증은 모든 로컬 종류에 적용된다.
- Windows 실제 DPI·고대비와 네이티브 실행 사용성 확인은 별도 수동 검증이다.

## 이번 구현 검증

- `flutter test`: 전체 48개 통과. 공통 입력 폼·저장소 종류 확장에 따른 다른 기록 메뉴 회귀를 포함한다.
- 테스트 명령은 총 3회: 새 기능 테스트, 찾기 조건 수정 후 실패한 1개 재실행, 최종 전체 테스트 1회.
- `flutter analyze`: 문제 없음. `flutter build web`, `flutter build windows`: 각각 1회 성공.
- Windows 네이티브 UI 수동 실행 확인은 하지 않았으며 위젯 크기·글자 확대 검사와 Windows 빌드로 검증했다.
