# 졸업 요건과 개인 학업 작업 공간

- 2026-10-15: 표 제목·헤더의 예시/목업 문구를 제거했다. 데이터 표시 스위치와 fixture 행은 유지하며 공식 졸업 판정이 아니라는 데이터 성격 안내도 유지한다. 판정·데이터 연결을 새로 구현한 것은 아니다.

## 교육과정 행렬의 탐색 전환

- `내 교육과정` 예시 행렬은 구분 열 92px, 나머지 열 최소 58px 및 카드 여백·테두리를
  포함한 최소 폭을 작업 공간에 전달한다. 현재 15열에서 필요한 본문 폭은 942px이다.
- 펼친 메뉴와 AI 도킹 때문에 이 폭이 부족하면 메뉴를 먼저 아이콘으로 접는다. 그 뒤에도
  부족할 때만 행렬의 공통 헤더·행 컨테이너에 가로 스크롤바를 표시한다.
- 다른 기준 탭·개인 기준 작업 공간·다른 메뉴로 이동하거나 목업 표를 숨기면 이 요구를
  해제한다. 창을 넓히거나 AI를 닫아 공간이 확보되면 메뉴를 복원한다.

## 현재 구현

- 세로 본문은 16px 스크롤 여백을 예약하며 교육과정 행렬의 최소 폭에도 이를 포함한다.
  개인 학업의 학교·학과·교육과정·과목·규칙 목록도 같은 스크롤 여백을 사용한다.

- 개인 학업 공통 헤더는 한글 제목과 개인 자료/공식 판정 구분을 표시한다.
- 졸업 요건 제목과 개인 기준 설정 버튼은 공통 헤더에 배치한다. 예시·API 미연결 문맥은
  제목 아래로 옮기고, 목업이 꺼졌을 때는 예시라고 표시하지 않는다. 실제 학교 정보는 생성하지 않는다.
- 개인 작업 공간의 탭과 각 목록 헤더는 왼쪽 시작선을 공유하며 탭 아래 간격은 12px이다.
- `graduation_page.dart`는 API 미연결 상태를 명시하고 기존 졸업 표를 예시로만 표시한다.
  목업 스위치를 끄면 예시 표 대신 미연결 안내를 표시한다.
- `내 학교·학과 기준 설정`에서 교육과정 → 교육과정 과목 → 개인 규칙을 관리한다.
  세 목록은 본문 등록 폼에서 실제 계정의 서버 자료로 저장하며 debug 샘플/기기 원본은 별도 로컬 키에 남는다. 추가·수정·확인 후 삭제와 재조회·버전 충돌 처리를 제공한다.
- 교육과정: 이름, 개인 학교·학과, 입학연도, 교육과정 연도, 메모·출처 URL.
  설정의 학업과 계획 프로필과 별개인 교육과정별 적용 범위이며 프로필 수정으로 규칙을 초기화하지 않는다.
- 과목: 이름·코드·학점·이수구분·개인 필수 여부, 개인 교육과정과 선택적 수강 기록 연결.
- 규칙: 이름·코드·종류·개인 적용 범위, 필요한 값·직접 확인한 현재 값·단위,
  조건/대체 요건/성적 기준 설명, 적용 시작·종료일, 출처 URL.
  개인 교육과정, 선택적 교육과정 과목, 수강·활동·경험·자격·성과 기록을 연결한다.
- 실제 계정의 관계는 목록에서 고른 본인 서버 UUID다. 규칙과 연결 과목의 교육과정이 다르면 저장을 거부한다. 다른 자료가 참조하는 서버 기록의 삭제는 409로 막으며 먼저 연결을 해제해야 한다. debug/기기 원본의 끊긴 참조는 원본을 보존하고 이전 전에 검토해야 한다.
- 연도 형식, 양의 학점, 음수·비유한 값, 실제 날짜·적용 기간, 안전한 URL을 검증한다.
  저장 성공 뒤만 목록을 바꾸고, 실패 시 작성 값·기존 저장 내용을 보존한다.
- 개인 교육과정·규칙의 출처 URL은 확인 뒤 외부 열기·복사를 제공한다.
  링크를 여는 것은 공식 근거 검증이나 졸업 판정이 아니다. [외부 링크](external-links.md)를 따른다.

## 목업·API 경계

- 개인 자료는 공식 학교·교육과정·규칙 마스터가 아니다. 서버의 본인 자료로 저장하지만 파일 업로드·공식 RAG 등록은 하지 않는다.
- 현재 값과 조건은 사용자가 기록한 내용이며 규칙을 실행하는 표현식이나 서버 enum이 아니다.
  Flutter는 충족·미충족을 계산하지 않는다. 기존 화면 내부 숫자 비교 목업은 제거했다.
- 졸업 판정·개인 계산은 서버 Rule Engine 책임이다. 실제 계정은 별도 `개인 기준 계산·이력`에서 명시 조건을 입력해 계산 결과를 조회한다. 규칙 입력 폼의 자유 문장을 자동 실행하지 않는다. 공식 표의 예시 결과는 개인 입력으로 변경되지 않는다.

  [화면 연결](../../api/personal-calculation-integration.md)을 따른다. 학교 확정 자료·공식 졸업감사·
  자동 실시간 동기화는 후속이며 문자 성적을 임의 환산하지 않는다.

- Windows 실제 DPI·고대비와 네이티브 실행 사용성 확인은 별도 수동 검증이다.

## 이번 구현 검증

- `flutter test`: 전체 48개 통과. 공통 입력 폼·저장소 종류 확장에 따른 다른 기록 메뉴 회귀를 포함한다.
- 테스트 명령은 총 3회: 새 기능 테스트, 찾기 조건 수정 후 실패한 1개 재실행, 최종 전체 테스트 1회.

- Windows 네이티브 UI 수동 실행 확인은 하지 않았으며 위젯 크기·글자 확대 검사와 Windows 빌드로 검증했다.

## 2026-10-14 작성 내용 취소 보호

명시적 취소 시 신규 작성 내용 또는 원본 대비 변경이 있으면 폐기 확인을 표시한다.
계속 작성은 입력과 선택을 보존하고, 내용 폐기만 닫는다. 빈 신규·무변경 수정은 확인 없이
취소한다. 저장 중 차단과 저장 실패 입력 보존은 유지한다. 공통 구현과 검증 범위는
[공통 입력 검증](../verification/ux-ui-verification.md)을 따른다.

## 2026-10-14 가독성 개편

- 대학 공통·학과 요건은 가용 폭 600px 미만 또는 14px 글자 확대 결과 18px 초과에서 항목별 제목·값·상태 묶음으로 표시한다. 교육과정 비교 행렬은 기존 가로 스크롤을 유지하며 예시를 공식 판정으로 바꾸지 않는다.
- 관련 기록/작업 공간 회귀 41개와 활동 예시 분리 신규 검사 통과. 최종 검증은 [1·2·4 검증 기록](../verification/ux-124-verification.md)을 따른다.

## 2026-10-17 개인 학업 관리

- 학생의 개인 작업 공간은 학교·학과·교육과정·교육과정 과목·개인 규칙의 목록/본문 입력을 제공한다. 관리자 repository와 분리된 기기 로컬 개인 기록이다.
- 개인 학교/학과는 별도 v1 키를 쓰고 기존 교육과정·과목·규칙 키와 ID는 유지한다. 기존 자유 입력 학교/학과도 보존하며 선택한 학교/학과를 교육과정에 연결할 수 있다. 잘못된 학교–학과 및 삭제된 참조는 저장 시 검증한다.
- 등록·수정·삭제, 실패 입력 보존·탭 변경 폐기 확인·좁은 폭 세로 배치를 제공한다. 변경 없는 수정 취소는 확인하지 않는다. 삭제는 연결 기록을 연쇄 삭제하지 않는다.
- 교육과정의 '학업 프로필로 사용'은 사용자가 명시적으로 선택한 학교·학과·입학연도·교육과정명을 PlanningRepository에 저장한다. 기존 일정과 주 시작 요일 등은 유지한다.
- 프런트는 규칙을 실행하거나 공식 충족 판정을 계산하지 않는다. 개인 기준 계산·서버 동기화·RAG는 계약 대기다.
- 개인 학업 회귀: 학교/학과 생성·작성 보호 신규 검사, 기존 관계/숫자 검증, 교육과정/과목/규칙 CRUD·재진입·삭제 참조, 480×520/200% 입력 접근 통과. 전체/분석/빌드는 세 구조 작업 마무리에서 수행한다.

최종 구조 변경 검증: [통합 검증 기록](../verification/structure-registration-verification.md)을 따른다.

개인 학교·학과의 별도 등록 탭은 debug/기기 작업 공간에서만 제공한다. 실제 계정의 서버 교육과정·과목·규칙과 개인 계산/이력은 기존 계약을 유지하며 기기 학교·학과를 서버 마스터로 자동 등록하지 않는다.
