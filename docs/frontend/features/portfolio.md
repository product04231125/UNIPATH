# 포트폴리오·성과

## 목적

프로젝트·논문·수상·발표를 개인 성과 기록으로 관리하고, 원본 기록과 지원 목적별 구성을
분리한다.

## 현재 구현

- `frontend/lib/features/records/portfolio/portfolio_page.dart`가 화면·입력 상태를 소유한다.
- 예시 행은 `frontend/lib/features/records/fixtures/portfolio_fixture.dart`에 있다.

## 목업 경계

- 현재 입력은 공개, 수상, 제출 완료, 저작권, 파일 업로드 상태를 확정하지 않는다.
- AI의 요약·문장·순서 제안과 공개 범위 변경은 확인 전 자동 반영하지 않는다.

## 후속 계약·검증

- 제목, 유형, 요약, 역할, 결과, 기간, 공개 범위, 자료 상태의 계약과 파일 정책을 합의한다.
- 직접 입력의 메뉴 내 반영을 위젯 테스트한다.
