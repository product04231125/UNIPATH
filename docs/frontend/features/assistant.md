# AI 도우미

## 목적

AI 도우미는 기록·탐색·문서 설명을 보조한다. 졸업 충족 판정, 학교 승인, 필수 요건을 스스로
결정하거나 기록을 자동 변경하지 않는다.

## 현재 구현

- `features/assistant/assistant_panel.dart`와 `assistant_conversation.dart`에 도킹 패널과 로컬
  대화 상태가 있다.
- `workspace.dart`가 열림·닫힘·폭·분리 창 상태를 조정한다.
- Web은 `window.open()` 경로, Windows는 네이티브 보조 창 경로를 사용한다.

## 목업 경계

- 대화 내용은 RAG 검색 결과, 인용 근거, LLM 답변 또는 서버 저장 이력이 아니다.
- 창 분리와 대화 상태는 영구 저장되지 않는다.

## 후속 계약·검증

- 대화 본문, 제공된 근거 표시, 재시도 가능한 상태를 합의된 API 계약에 맞춰 화면에 연결한다.
  검색·근거 선택·오류 enum의 의미는 이 문서에서 정의하지 않는다.
- 열기·닫기·분리·전면화 및 좁은 폭 오버레이 동작을 Web·Windows에서 검증한다.
