# 휴대폰 세로 Web 하단바 검증 (2026-11-03)

현재 정책은 [제품 UX](../product-ux.md)·[탐색](../features/navigation.md)·[플랫폼 차이](../platform-differences.md)를 따른다.

## 범위

- 판별: `width < 600 && height / width > 1.6` (`isPhonePortraitShell`)
- 셸: 학생 하단바 5+더보기(일정·졸업 요건·홈·자료·채용공고 분석·더보기), 관리자 4+더보기.
  Web 상단 제목/탐색 chrome 숨김, 목업·서비스 재설명 문구 숨김. 계정 보안은 설정 `계정·정보`만.
- 휴대폰 밀도: 하단바 높이 56, 페이지 제목 22, 헤더 아래 간격 12, 본문 패딩 12 (`PhoneChromeScope.active`만. Scope가 없으면 화면 비율로 추정하지 않음)
- 비대상: `480×520`·정확 `480×768`(비율 1.6)·`900×768`은 좌측 메뉴. 샘플 로그인 부울(`kShowDebugSampleLogin=false`) 미변경

## 자동 검증 (위젯)

구현 커밋 `d8c4546`(메뉴), `076f8d9`(설정 계정 보안), `7a920fb`(하단 순서), `b063d08`(밀도).

- `phone_shell_test`: `360×800`·`390×844`·`430×932`에서 학생 바 라벨
  `일정, 졸업 요건, 홈, 자료, 채용공고 분석, 더보기`, 바 높이 56. 더보기 시트에
  수강 관리·활동·자격·설정·로그아웃, `계정 보안` 없음. AI 전용 보기에서 하단바 숨김.
  `1440×900` 좌측 메뉴, `480×520` 아이콘 레일. Scope 없는 `390×844`는 chrome 비활성.
- `account_settings_entry_test`: `1440×900`·`480×520`·`390×844` 제목표시줄에 계정 보안·신청
  아이콘 없음. 설정 `계정·정보`에서 기존 모달 콜백.
- `page_header_test`: phone chrome에서 제목 22, 헤더 아래 간격 12.
  `390×844`에 Scope가 없으면 제목은 넓은 화면 26px.

위젯은 `startAuthenticated`로 셸만 확인한다. 아래 브라우저 실기와 구분해 적는다.

## 브라우저 실기 — 로그인 화면 (2026-11-03)

- `flutter run -d web-server --web-port 3000` 후 MCP 브라우저에서
  `Emulation.setDeviceMetricsOverride`로 `390×844` (`mobile: true`) 적용.
- 확인: 로그인 화면이 이메일·비밀번호·로그인만 보이고, 학생/학교관리자/슈퍼관리자
  샘플 진입 버튼은 없다. 당시 실계정 세션이 없어 인증 후 하단바는 위젯에 위임했다.

## 브라우저 실기 — 인증 후 390×844 (2026-11-04)

호스트 `http://localhost:3000`만, API `http://127.0.0.1:8010`.
`flutter run -d web-server --web-port 3000 --web-hostname localhost --dart-define=API_BASE_URL=http://127.0.0.1:8010`
(밀도 커밋 `b063d08` 이후 재시작). MCP `cursor-ide-browser`, 뷰포트 `390×844`.
`kShowDebugSampleLogin`은 켜지 않았다. 기존 브라우저 자동완성으로 학생 실계정에 로그인했다.
신원·이메일은 기록하지 않는다.

### 브라우저에서 확인

| 항목 | 결과 |
| --- | --- |
| 하단 순서 | 일정, 졸업 요건, 홈, 자료, 채용공고 분석, 더보기. 시작 후 일정(`/schedule`)이 첫 주 목적지 |
| 더보기 시트 | 수강 관리, 활동, 자격, 설정(현재 선택 강조), 로그아웃. **계정 보안 없음** |
| 설정 → 계정 보안 | 설정 `계정·정보`에 `계정 보안`·(해당 시) `학교 관리 권한·신청 이력`. 모달 제목 `계정 보안`, 비밀번호 변경·모든 기기 로그아웃·닫기. 데스크톱과 같은 모달 |
| 휴대폰 제목줄 자물쇠 | Web 휴대폰에서 상단 제목/뒤로/사이드바 chrome 없음. 본문 `PageHeader`만. 자물쇠 없음 |
| 밀도 | 홈(주간 카드·준비 목록이 첫 화면), 일정(달력), 자료, 채용공고 분석, 설정. 헤더·하단바가 본문을 과도하게 밀지 않음. 긴 폼의 **데이터 스크롤**은 유지 |
| AI 오버레이 | `AI 도우미` 전용 보기에서 하단바 사라짐. 닫으면 바 복귀 |

### 위젯만 / 브라우저 미완

- `360×800` 브라우저: 이번 세션에서 반복하지 않음. 위젯 `phone_shell_test` 세 크기와 동일 라벨·높이.
- 넓은 Web 작업 공간 제목줄: MCP 캡처가 약 481px로 잘려 `1440×900` 전체 제목줄을 한 화면에 못 봄.
  뷰포트를 넓힌 뒤 Flutter 세션이 로그인 화면으로 돌아가 인증 후 데스크톱 제목줄은 재확인하지 못함.
  위젯 `account_settings_entry_test`가 `1440×900`·`480×520`에서 자물쇠/신청 아이콘 없음을 단언.
  코드 `workspace_title_bar.dart`에도 계정 아이콘이 없다. 로그인 화면 `480×520` 상단은 `UniversityPath`만.
- Codex 리뷰는 이 단위 밖이다.

## 남은 차단

- `360×800` 브라우저 실기는 위젯으로 대체한 상태다.
