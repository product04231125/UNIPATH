## 재검토에서 추가 발견·수정

- 서로 다른 개인 기록 저장소 객체의 연속 저장/삭제가 이전 스냅샷으로 다른 기록을 덮어쓰는 문제를 회귀 검사로 재현했다. 종류별 큐와 쓰기 직전 최신 값 읽기로 해결했다. 완료 큐는 즉시 해제한다. 저장 키 삭제 후 재읽기에도 이전 메모리 목록을 남기지 않는다.
- 학업 정보 저장 중 소유자가 폐기되면 완료 시 폐기된 ChangeNotifier를 알리는 오류를 재현했다. 승인된 저장은 마무리하고 폐기된 리스너에는 알리지 않으며 신규 작업은 거부한다.
- 실제 Web에서 좁은 AI를 닫았다 다시 열면 포커스가 AI 밖에 남아 Esc가 동작하지 않는 것을 재현했다. 활성화 시 이전 AI 제어 또는 첫 제어로 포커스를 복원한다. 기존 키보드 검사에 재열기 검증을 추가했다.

## 검토 범위와 결과

- 인증/역할/라우팅, Workspace 소유권, 내부·분리 AI/IPC/지연 응답, 설정·일정 저장, 개인 기록·포트폴리오 참조, 관리자 권한·버전/삭제, 공통 입력·탐색·테마와 관련 테스트를 대조했다.
- 최신 `origin/develop`을 merge로 통합했다. 백엔드 규칙/백업 작업은 develop의 기존 변경이며 이 프런트 변경의 새 구현으로 간주하지 않는다.
- 위에서 확인된 결함은 수정·회귀 검증을 마쳤다. 검토 범위에서 추가로 확인된 미수정 결함은 없다. 모든 환경에서 버그가 없다는 보장은 아니다.
- 실제 인증/서버 기록·공식 판정·RAG/CSV/파일 연동의 미완료 기능은 기존 계약 의존성으로 구분했다. 새로운 API·서버·권한 계약을 추측하거나 구현하지 않았다.

## 검증

- SDK 3.47.5. 전체 테스트 최종 275개 통과. 마지막 포커스 수정 후 영향받은 키보드/학교 폼/창 선호/달력 38개 추가 통과.
- 테스트 명령 총 17회: 재현 전 실패, 수정 후 선택 검사, 전체 2회와 실패 진단 포함. 첫 전체 실행은 저장 큐의 이전 비동기 실행 영역 대기로 중단했다. 큐 해제 수정 후 관련 42개 및 전체 275개가 통과했다.
- 전체 `flutter analyze` 2회(첫 서식 경고 5개 수정 후 통과), 추가된 Windows 도구 및 마지막 변경 파일의 `dart analyze` 각 1회 통과.
- 제품 Web/Windows 빌드 각 2회 성공. 실제 Web에서 추가 포커스 오류를 발견·수정했으므로 두 플랫폼을 다시 빌드했다. Windows 합성 검사 대상은 별도 실행 빌드 1회다.
- 실제 Windows: `flutter run -d windows -t tool/chat_session_smoke.dart --release`. HTTP/사용자 데이터/기기 선호 저장 없이 합성 입력으로 두 세션을 생성·종료했다. 일반 닫기 거부 콜백이 있어도 로그아웃 종료는 작동하고 자식 창 부재·새 세션 입력 분리를 확인했다.
- 실제 Web: 한국어·크림·브라운, 1440×900/480×520. 지원 문서 메뉴 복귀, AI 초안 닫기/재열기, 최종 재열기 포커스·Esc·열기 버튼 복귀 확인.
- 비추적 검증 산출물: `frontend/build/pr14-*.log`, `chat_session_smoke.json`, `pr14-portfolio-return-480.png`, `pr14-ai-reopen-focus-480.png`.
