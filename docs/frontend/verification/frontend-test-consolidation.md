## 전체 검토 후 유지한 사례

- 관리자 과목 등록/연결: 부분 성공, 응답 유실 재조회, ID 재사용, 다른 교육과정 보존은 서로 다른 실패 조건이다. 관련 API·상태·UI 테스트를 삭제하지 않았다.
- 동의 취소/이번만 허용, 409/422, 분석 상태, owner·버전·학교 범위 검증은 유지했다.
- 카드/열·헤더·입력 다이얼로그·홈·주간 일정·채팅 가림·공식 감사·외부 링크 확인·학교 권한 신청은 크기에 따른 배치·스크롤·상태 전환을 함께 검증하므로 유지했다.
- 계정 보안·원격 수강 편집·개인 계산·논문·학교 지식 검토의 크기/확대 조합은 입력 오류·닫기 확인·가림 위험을 포함하므로 유지했다. 키보드 순회·휴대폰 셸 판정·전환 경계도 유지했다.
- API wire 계약, 저장소 상태, 화면 표현은 관측 계층이 다르면 중복으로 간주하지 않았다. 기존 캡처와 서버 환경 의존 생략 조건은 변경하지 않았다.

## 검증

- 환경: Windows, Flutter 3.47.5 / Dart 3.13.4. CI는 고정 Flutter 3.47.6으로 별도 검증한다.
- 비교 명령: frontend에서 `flutter test --reporter expanded`. 동일 장비·옵션이며 의존성 확인과 프로세스 시작을 포함한 전체 명령 시간이다. 시간은 1회 측정이며 성능 개선을 보장하지 않는다.
- 변경 전: **830 통과 / 13 생략 / 0 실패**, 테스트 reporter 64초, 전체 명령 **79.44초**.
- 변경 후: **824 통과 / 13 생략 / 0 실패**, 테스트 reporter 69초, 전체 명령 **73.59초**. 실행 사례 6건 감소. 전체 명령은 5.85초 줄었지만 reporter 시간은 5초 늘었다. 의존성 확인·캐시·실행 변동이 섞인 단회 측정이므로 테스트 자체가 빨라졌다고 결론 내리지 않는다.
- `flutter analyze --no-pub`: 문제 없음. Draft PR의 Frontend CI 결과는 해당 PR checks에서 확인한다.
- 변경 파일 회귀: **71 통과**. 제품 코드와 플랫폼 빌드 입력이 바뀌지 않아 Release 재빌드는 하지 않는다. 운영 계정·실서버·브라우저 수동 검증은 이번 테스트 정리 범위에 포함하지 않는다.
