# 학교 확인 학생 기록 화면 검증 · 2026-10-24

- 기존 OfficialRecordsApi, RecordSourceApi, 학생 과목/자격 카탈로그만 연결. 서버/API 변경 없음.
- 네 종류 입력의 typed 값, 소수 3.500001 보존, 과목/자격 현재 판, 미확인 값 유지 검사 통과.
- 1440×900/480×720: 원본 기반 초안·문맥·쪽수·기준일·일부 검토, 실패 입력/행 보존과 동일 키
  재시도, 원본 메타데이터 전송 검사 통과. 좁은 화면은 실제 스크롤 후 하단 행동에 접근한다.
- 승인 조건 3개·판/원본 해시, 승인 후 편집 제어 종료, 학생 읽기 전용 및 소수 표시 검사 통과.
- API 회귀 7개 통과. UI는 누락 import 1회 수정, 초기 선택값 조회 전 표시 오류 수정,
  좁은 화면 스크롤 테스트 보완 후 8개 통과. 실패 보존 추가 후 UI/API/원본/감사 총 20개 통과.
- 분석에서 테스트 조건문 1개와 미사용 필드를 정리한 뒤 문제 없음. 행 취소 보호 변경 후
  네 종류 입력 4개 재검사 통과. Web/Windows 각 1회 빌드 성공(행 취소 보호 정리 전).
  전체 흐름 마무리의 최종 코드로도 양쪽 빌드 성공. [종합 기록](school-workflows-2026-10-24.md)을 따른다.
- 운영 데이터 등록/승인, 실제 신원 확인, Windows 네이티브 사용성은 미검증.
  기존 승인 교체 지정 UI는 이 단위에 포함하지 않았다.
