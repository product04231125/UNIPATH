# 미등록 학교 관리자 신청 폼 검증 · 2026-10-24

## 구현 경계

- 기존 신청창에 등록/미등록 유형과 학교 목록 재조회를 추가했다. 학교 목록이 비어도 폼은 표시한다.
- 별도 창 내부 초안에서 학교명·홈페이지·계정 이름·직책·이메일·사유를 작성한다.
  유형 간 입력을 따로 보존하고 닫기/재시작 후 저장하지 않는다.
- 미등록 학교에서는 비활성 접수 버튼과 미저장 안내만 제공한다. 기존 신청 DTO·서버/API는 변경하지 않았다.
- 접수 API가 없는 미등록 학교의 서버 제출·검토 이력은 연동 대기다. 실제 접수 완료로 표시하지 않는다.

## 검증

- 기존 신청/취소/동일 키 재시도/승인·반려 UI 6개 최초 통과.
- 신규 5개: 학교 0건에서 미등록 입력, 이름 읽기 전용, POST 미발생·성공/가짜 이력 없음,
  닫기/계속 작성/폐기/재진입 시 초기화, 두 유형 별도 보존·등록 학교 실제 전송 및 새 학교 목록 갱신,
  필수·이메일·URL 검증과 모든 최대 길이를 확인했다.
- 크기: 1440×900, 480×720, 480×520·글자 200%. 입력·하단 버튼·폐기 확인에 스크롤로 접근하고 오류 없음.
- 신규 테스트 최초 읽기 전용 속성 참조 오류를 수정했다. 첫 수정 명령은 잘못된 상대 경로로 적용되지 않아
  컴파일 실패가 반복됐다. 절대 경로로 수정 후 신규 5개 통과.
- 최종 `flutter test --no-pub` 대상: 신규 폼, 기존 신청 UI, 신청 API, 공통 학교 흐름 상태 **26개 통과**.
  단일 기능 변경으로 전체 검사를 반복하지 않았다. 대상 명령은 기존 1회·신규 3회(컴파일 실패 2회 포함)·최종 1회다.
- `flutter analyze --no-pub` 1회 문제 없음. `flutter build web --no-pub`,
  `flutter build windows --no-pub` 각각 1회 성공.
- 실제 서버/학교 등록·운영 심사와 Windows 네이티브 실기는 미검증이다. 요청 범위는 입력 폼 준비다.
