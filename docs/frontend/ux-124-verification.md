## 검증 결과

- Flutter SDK 3.47.5. 전체 `flutter test` 최종 255개 통과. 실화면의 마지막 관리자 라벨/간격 보완은 관리자 38개·폭 관련 3개·교육과정 이력 복귀 신규 1개 추가 통과.
- `flutter analyze` 문제 없음, `flutter build web`, `flutter build windows` 최종 통과.
- 실제 Web: 크림 1440×900 관리자 현황·등록 폼·설정 확장 공간·도킹 채팅, 480×520 채팅/닫기·다크 퍼플 활동 목록. 200%·저장 오류·폐기 보호는 자동 검사로 확인했다.
- 독립 `tool/window_geometry_smoke.dart`: 실제 Windows 2모니터/DPR 1.0에서 제목표시줄 숨김, 네이티브 화면 안 좌표 복원, 메인 유지, 공간 부족 판별, 최대화/복원 성공. 합성 검사 창만 사용하며 개인 선호·기록을 읽거나 수정하지 않는다. `--dart-define=NATIVE_REPORT_PATH=<절대 결과 경로>`로 보고서를 지정할 수 있다.
- 검사 중 구 구조를 기대하던 카드/설정 비교 테스트와 좁은 200% 채팅 높이 문제가 발견되어 수정했다. 접힌 안내에 외부 도구까지 숨겼던 부분도 직접 접근으로 보완했다. 네이티브 검사 도구는 준비 전 taskbar 호출과 결과 경로를 진단/보완한 뒤 성공 결과를 확인했다.

## 한계와 후속

- 모니터 1대/3대 이상·혼합 DPI·물리 연결/해제·마우스 스냅·고대비·스크린리더 전체 실기는 미검증이다. 제거/음수 좌표와 오른쪽 공간 부족은 합성 단위 검사로 확인했으며 실제 모든 하드웨어 조합을 검증한 것으로 취급하지 않는다.
- 메인 창의 숨겨진 제목표시줄은 기존 리사이즈 가능한 OS 창을 유지한다. 분리 채팅 창의 OS 상단은 이번에 별도로 재설계하지 않았다.
- 최종 브랜드 팔레트/삭제 시안 선택은 사용자 결정 대기이며 네 팔레트 비교를 유지한다. 새 테마·글자·접근성 설정, 파일 중심 포트폴리오, 관리자 신청, 개인 표 편집, CSV/API는 별도 후속이다.
- 이 변경은 로컬 커밋이며 별도 요청 전 제품 원격/PR에 게시하지 않는다.

검사 실행 이력: 전체 회귀 2회(실패 후 수정 재검증), 분석 4회(초기 lint·렌더 보완·마지막 탐색 보완), Web/Windows 빌드 각 3회. 네이티브 합성 검사 4회 중 마지막 성공. 단위별 관련 검사·수정 후 재검사는 위 결과와 기능 회귀를 따른다.
