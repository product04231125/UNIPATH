# 홈 UX/UI 기준

## 목적

홈은 통계 대시보드가 아니라 학생이 **지금 무엇을 해야 하는지** 선택하는 시작점이다.
첫 화면에서 졸업 가능 여부를 단정하거나 AI 대화를 강요하지 않는다.

## 권장 구성

- 상단에는 학생의 학교·학과·입학연도와 한 문장의 환영/목적 안내를 둔다. 개인정보가
  아닌 적용 범위 요약이므로 길게 늘어놓지 않는다.
- 가장 위에는 하나의 주 행동을 둔다. 예: `이번 학기 기록 정리`, `졸업 요건 확인`.
  주 행동은 현재 부족한 정보나 학기 시점에 따라 바뀔 수 있으나, 동시에 여러 개를
  강조하지 않는다.
- 2×2 카드에는 `학사 기준`, `이번 학기와 활동`, `공식 문서`, `성과와 진로`처럼
  다음 메뉴로 가는 이유와 현재 요약만 표시한다. 카드 전체는 하나의 명확한 목적지로
  연결하고, 상태 배지를 별도 버튼처럼 보이게 하지 않는다.
- 요약 수치는 최근 갱신 시각 또는 데이터 출처를 함께 표시한다. 아직 학교 데이터가
  연결되지 않았으면 수치 대신 연결/입력 안내를 보인다.

## 상태와 상호작용

| 상태 | 표시 방식 |
| --- | --- |
| 첫 사용 | 1~3개의 시작 과업만 보이고, 미입력 데이터를 실패처럼 표시하지 않는다. |
| 기록 부족 | "활동 0건"보다 `첫 활동 기록하기`처럼 다음 행동과 필요한 정보 예시를 제시한다. |
| 학교 데이터 갱신 대기 | 마지막 동기화 시각과 새로고침/학교 시스템 확인 안내를 제공한다. |
| AI 사용 | 우측 AI는 기본 닫힘이며, 홈 카드가 AI를 자동으로 열거나 기록을 자동 변경하지 않는다. |

## 학교 제공 정보가 없을 때

- 학교·학과 데이터가 비어 있으면 실패 수치 대신 `내 학교·학과 기준 설정`과 첫 수강·활동
  기록 추가를 제시한다. 학교가 지원되지 않아도 개인 기준과 기록 관리로 시작할 수 있다.
- 홈은 `개인 기준`과 `공식 학교 기준`을 구분해 요약하며, 개인 기준 계산을 공식 졸업
  판정이나 학교 연결 완료로 표현하지 않는다.
- 자세한 개인 기준·기록 상태는
  [`../student-contributed-school-information-ux.md`](../student-contributed-school-information-ux.md)를 따른다.

## UI 검토 기준

- 일반 데스크톱 높이에서 세로 스크롤 없이 핵심 행동과 카드가 보이는지 확인한다.
- QHD처럼 넓은 화면에서도 카드 안의 글이 과도하게 넓어지거나 빈 여백만 커지지 않는지
  확인한다.
- 카드는 제목·짧은 설명·상태의 순서를 유지하고, 색을 빼도 우선순위를 읽을 수 있어야
  한다.
