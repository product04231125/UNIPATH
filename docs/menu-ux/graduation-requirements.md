# 졸업 요건 UX/UI 기준

## 목적

졸업 요건 메뉴는 학생의 학교·학과·입학연도·교육과정에 맞는 **Rule Engine 판정**을
투명하게 보여 주는 화면이다. AI는 공식 문서 근거를 설명하지만 판정을 대신하지 않는다.

## 권장 구성

- 입장 즉시 적용 범위(학교, 학과, 입학연도, 교육과정)와 통합 판정 요약을 보여 준다.
  사용자가 별도 버튼을 누르기 전부터 여러 기준 표를 한꺼번에 펼치지 않는다.
- 요약은 `미충족`, `확인 필요`, `충족`처럼 적은 상태로 구성하고, 각각에 부족한 값·
  확인할 정보·다음 행동을 텍스트로 둔다.
- `대학 공통`, `내 교육과정`, `학과 기준`은 탭 또는 기준 선택으로 하나씩 전환한다.
  현재 기준 이름과 적용 이유를 탭 아래에 유지한다.
- 각 행은 요건, 현재 상태, 판정, 공식 근거 행동을 가진다. `공식 기준 확인`은 문서명,
  적용 범위, 페이지가 담긴 AI/문서 패널을 연다.
- 교육과정 학점 행렬은 요건 판정 표와 분리한다. 이 표에는 판정 배지를 반복하지 않고
  졸업 기준·취득·신청·부족 값처럼 비교에 필요한 수치만 둔다.

## 상태와 상호작용

| 상태 | 표시 방식 |
| --- | --- |
| 데이터 충분 | Rule Engine의 충족/미충족 결과와 산식에 쓰인 공식 기록 범위를 표시한다. |
| 데이터 부족 | `확인 필요`와 필요한 공식 데이터(학적, 승인 봉사 등)를 표시한다. 추정 판정을 만들지 않는다. |
| 근거 존재 | 문서명·페이지·적용 범위를 열 수 있게 한다. |
| 근거 부족 | `근거 부족`을 명시하고 출처처럼 보이는 빈 카드나 AI 추측을 표시하지 않는다. |

## 학교 제공 정보가 없을 때

- 적용 가능한 학교·학과·교육과정 규칙이 없으면 `공식 기준 미등록`을 표시하고,
  `학교 정보 직접 추가`로 규정 문서의 범위·조항·페이지를 개인 참고 또는 검토 후보로
  남길 수 있게 한다.
- 이 입력에는 항상 “검토 전에는 졸업 판정에 사용되지 않습니다”를 표시한다. 학생 입력,
  AI 요약, 출처 URL만으로는 충족·미충족을 계산하거나 기존 판정을 수정하지 않는다.
- 관리자가 원문과 범위를 검증해 공식 데이터로 반영한 뒤에만 새 Rule Engine 감사를
  실행한다. 세부 상태는
  [`../student-contributed-school-information-ux.md`](../student-contributed-school-information-ux.md)를 따른다.

## UI 검토 기준

- 상태 색상만으로 판정을 전달하지 않으며, 모든 상태에 짧은 텍스트와 다음 행동이 있는지
  확인한다.
- 숫자 요약은 보조 정보이며 원형 게이지나 장식이 요건·부족 항목보다 먼저 주의를
  빼앗지 않는지 확인한다.
- 공식 기록 갱신 전에는 "학교 승인된 기록을 올려 주세요"처럼 사용자 행동을 안내하고,
  앱이 학교 승인 여부를 대신 판단하는 문구를 피한다.
