# 메뉴별 UX/UI 기준

이 폴더는 학생 화면의 각 메뉴가 해결해야 할 사용자 과업, 필요한 UI 구성, 상태 표현,
AI·공식 데이터 경계를 정리한다. 공통 창·반응형·접근성 기준은
[`../web-windows-ux-guidelines.md`](../web-windows-ux-guidelines.md), 설정의 정보 구조는
[`../application-settings-ux.md`](../application-settings-ux.md)를 우선한다.

| 메뉴 | 문서 | 핵심 과업 |
| --- | --- | --- |
| 홈 | [home.md](home.md) | 지금 할 일과 다음 진입점 선택 |
| 수강 관리 | [course-management.md](course-management.md) | 학교 수강 내역 확인·다음 학기 계획 정리 |
| 졸업 요건 | [graduation-requirements.md](graduation-requirements.md) | Rule Engine 판정·적용 기준·공식 근거 확인 |
| 활동 | [activities.md](activities.md) | 교내외 활동·봉사 기록과 학교 승인 상태 관리 |
| 경험 | [experiences.md](experiences.md) | 사실 기반 경험을 역할·행동·결과로 정리 |
| 자격 | [certifications.md](certifications.md) | 취득 자격·어학·교육 이수와 유효 기간 관리 |
| 포트폴리오·성과 | [portfolio-outcomes.md](portfolio-outcomes.md) | 산출물·링크·성과를 목적별 포트폴리오로 구성 |
| 설정 | [settings.md](settings.md) | 드물게 바꾸는 개인화·계정·정보 설정 |

각 문서는 설계 기준이며, 문서에 제안된 UI가 모두 구현됐다는 뜻은 아니다. 화면을
변경할 때는 현재 구현과 제안을 구분해 검증한다.
