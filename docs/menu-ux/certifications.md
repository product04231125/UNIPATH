# 자격 UX/UI 기준

## 목적

자격증, 어학 성적, 교육 이수 내역을 취득 사실과 유효 기간 중심으로 관리하는 메뉴다.
Q-Net 등 외부 기관의 발급·시험·진위 확인을 대체하거나 자동으로 완료 처리하지 않는다.

## 권장 구성

- 목록의 기본 단위는 하나의 자격/성적/교육 이수다. 명칭, 발급 기관, 취득/응시일,
  유효 기간, 식별 번호의 마스킹 여부, 증빙 상태를 둔다.
- 상태는 `준비 중`, `취득`, `유효 기간 확인`, `만료`, `증빙 필요`처럼 행위가 분명한
  표현으로 제한한다. 취득과 목표 설정을 같은 목록/배지로 섞지 않는다.
- Q-Net 시험 일정, 어학 시험, 교육 과정 등은 `준비 탐색` 또는 AI 대화의 결과로
  안내한다. 부족한 자격을 자동 추천·등록하거나 취업 필수 조건처럼 단정하지 않는다.
- 자격 상세에는 증빙 파일/링크, 발급일, 만료일, 공개 가능 여부를 묶고, 원문 번호나
  민감한 식별값은 기본 마스킹한다.

## 상태와 상호작용

| 상태 | 표시 방식 |
| --- | --- |
| 준비 중 | 목표일 또는 다음 행동(일정 확인, 접수)을 표시하며 취득 기록으로 계산하지 않는다. |
| 취득 | 사용자가 등록한 발급 정보와 증빙 상태를 표시한다. |
| 유효 기간 확인 | 만료일 누락 또는 임박 이유를 텍스트로 표시한다. |
| 만료 | 기록은 보존하되 현재 유효 자격과 구분하고 갱신 행동을 제안한다. |

## 학교 제공 정보가 없을 때

- 학과 권장 자격, 대체 인정 안내, 교내 교육 과정 정보가 없으면 학생은 학교 공지의
  제목·링크·시행일·적용 대상을 직접 추가할 수 있다.
- 추가한 안내는 자격 취득·유효성·학과 필수 여부를 증명하지 않으며, Q-Net 등 발급
  기관 기록 및 학교의 공식 기준과 분리해 표시한다.
- 출처 없는 정보는 개인 준비 계획으로만 저장하고, 공식성 주장이나 자동 추천 근거로
  사용하지 않는다. 공통 상태는
  [`../student-contributed-school-information-ux.md`](../student-contributed-school-information-ux.md)를 따른다.

## UI 검토 기준

- 외부 사이트 바로가기는 외부 이동임을 표시하고, 인증 정보 입력을 UniversityPath 안에
  요구하지 않는다.
- 날짜 입력에는 예시와 형식을 제공하며, 유효 기간이 없는 자격은 `해당 없음`으로
  명시해 빈 날짜를 오류로 해석하지 않게 한다.
- 자격 증빙을 삭제하거나 공개 범위를 바꿀 때에는 영향 범위와 복구 가능 여부를 먼저
  안내한다.
