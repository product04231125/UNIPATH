# 수강 관리 UX/UI 기준

## 목적

학생이 학교 수강 시스템의 확정 과목을 확인하고, 현재/다음 학기 계획을 정리하는 메뉴다.
학교의 공식 수강 신청·성적 시스템을 대체하지 않는다.

## 권장 구성

- 상단에는 현재 학기, 학교 수강 내역 기준 여부, 마지막 반영 시각을 표시한다.
- `이번 학기`, `수강 예정`, `이수 내역`을 명확히 구분한다. 학점 분류·인정 영역·승인
  상태는 한 행의 보조 정보로 묶고, 과목명보다 앞서지 않게 한다.
- 기본 목록은 과목명, 구분, 학점, 상태, 공식 데이터 출처로 구성한다. 검색·학기 필터·
  분류 필터는 목록이 충분히 많아진 뒤에만 추가한다.
- 여러 열을 비교해야 하는 교육과정 행렬은 별도 영역에서 제공한다. 헤더·그룹 헤더·행이
  같은 가로 스크롤 안에서 움직여야 하며, 일반 수강 목록에 행렬을 강제로 섞지 않는다.
- 과목 추가/수정 전에는 `학교 수강 시스템에서 확정된 과목만 등록`한다는 안내와 공식
  수강 시스템으로 가는 경로를 둔다.

## 상태와 상호작용

| 상태 | 표시 방식 |
| --- | --- |
| 수강 내역 없음 | 학기 선택과 학교 수강 시스템 확인 안내를 표시한다. |
| 분류 미확인 | `확인 필요` 텍스트와 이유를 보이고, 미충족으로 단정하지 않는다. |
| 계획 과목 | 확정 수강 과목과 시각적으로 구분하며 졸업 판정 입력으로 자동 사용하지 않는다. |
| AI 도움 | 교육과정 인정 영역·다음 학기 계획을 질문할 수 있으나, AI 답변이 과목 분류나 학점을 확정하지 않는다. |

## 학교 제공 정보가 없을 때

- 교육과정, 과목 코드 또는 인정 영역이 없으면 `교육과정 정보 직접 추가`로 학교 공지의
  적용 연도·학과·과목 정보와 원문 출처를 남길 수 있게 한다.
- 학생이 적은 과목 분류는 `개인 참고` 또는 `출처 정보 입력됨`으로 과목 행에 분리해
  보이며, 공식 수강 내역·학점 인정·Rule Engine 입력을 자동 변경하지 않는다.
- 원문 없이 적은 계획 과목은 검토 요청 대상이 아니며, 학교 수강 시스템의 확정 과목과
  나란히 비교할 수 있게 한다. 공통 흐름은
  [`../student-contributed-school-information-ux.md`](../student-contributed-school-information-ux.md)를 따른다.

## UI 검토 기준

- 표는 과목 탐색에 필요한 열만 기본 노출하고 세부 정보는 행 확장 또는 상세 화면으로
  점진 공개한다.
- 정렬·필터가 있으면 현재 적용 조건과 결과 수를 텍스트로 표시하고 초기화 방법을 둔다.
- 과목 등록 폼은 한 화면에서 하나의 과목을 다루며, 과목 코드·학점·분류의 검증 오류를
  해당 필드와 함께 설명한다.
