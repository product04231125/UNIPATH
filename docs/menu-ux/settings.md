# 설정 UX/UI 기준

## 목적

설정은 학생이 드물게 바꾸는 개인화, AI·데이터, 알림, 접근성, 계정·정보를 다룬다.
필터·정렬·현재 탭·기록 수정처럼 현재 과업에서 바로 바꿔야 하는 값은 설정에 넣지 않는다.

## 메뉴 구성

- 좌측 탐색 하단의 `설정`에서 독립 본문 페이지로 연다.
- `일반`, `AI와 데이터`, `알림`, `접근성`, `계정·정보`처럼 5개 이하의 범주로 묶는다.
- 각 설정 행에는 제목, 한 문장 영향 설명, 현재 값 또는 제어 요소를 둔다. 비활성 항목은
  숨기지 말고 사용할 수 없는 이유를 설명한다.
- 기본값은 안전하고 단순해야 한다. 예: AI 패널 기본 닫힘, 시스템 글꼴·고대비 우선,
  공용 PC에서 자동 로그인/개인 기록 복원 기본 해제.

## 경계와 상태

| 대상 | 설정 여부 |
| --- | --- |
| AI 패널 기본 열림, 패널 폭 복원, 테마 | 개인 UI 선호로 설정 가능 |
| AI 이력 보존·삭제, 알림 수신 | 정책·API·권한이 구현된 뒤 설정 가능 |
| 학교·학과·입학연도·교육과정·학교 승인값 | 설정 불가. 공식 데이터/정정 흐름으로 처리 |
| 비밀번호, 토큰, 외부 API 키 | 설정 화면·로컬 저장소에 입력하거나 표시하지 않음 |

## 학생이 추가한 학교 정보

- `계정·정보` 아래에 `내가 추가한 학교 정보` 목록을 둔다. 항목별 상태, 출처, 적용 범위,
  마지막 수정일을 보여 주고 개인 참고와 검토 후보를 분명히 구분한다.
- 학생은 개인 참고를 수정·삭제하고, 출처 정보 입력됨의 검토 요청을 철회할 수 있다.
  `공식 반영됨` 상태를 직접 설정하거나 학교·학과·교육과정 공식값을 설정에서 바꾸는
  동작은 제공하지 않는다.
- 보관·삭제·권한 및 상태 전환은
  [`../student-contributed-school-information-ux.md`](../student-contributed-school-information-ux.md)를 따른다.

## UI 검토 기준

- 가역 변경은 즉시 반영하고, 삭제·연결 해제·로그아웃은 대상·영향·확인을 제공한다.
- 저장·삭제·동기화 실패에는 해당 행에 텍스트 오류와 재시도 행동을 남긴다.
- 시스템 전역 접근성 설정을 복제하지 않고, 앱이 이를 따르는지 확인한다.

## 상세 기준

저장 위치, 권한, 초기 MVP 범위, QA 체크리스트와 근거는
[`../application-settings-ux.md`](../application-settings-ux.md)를 따른다.
