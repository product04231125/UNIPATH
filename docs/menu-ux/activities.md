# 활동 UX/UI 기준

## 목적

교내 활동, 봉사, 동아리, 공모전 등 활동을 사실 기반으로 기록하고 학교 승인 여부와
개인 증빙을 구분하는 메뉴다. 1365·VMS 같은 외부 서비스와 학교 시스템을 대체하지
않는다.

## 권장 구성

- 목록의 기본 단위는 하나의 활동이다. 제목, 기관/유형, 기간 또는 시간, 본인 역할,
  학교 승인 상태를 한 행 또는 카드에 둔다.
- 봉사 활동은 `외부 기록`, `학교 제출`, `학교 승인`, `UniversityPath 기록`을 서로
  다른 상태로 표시한다. 외부 사이트에서 활동했다는 사실만으로 졸업 반영을 암시하지
  않는다.
- `활동 추가`에는 유형별 최소 입력(기관, 기간, 역할, 시간/결과)을 먼저 받고, 증빙
  파일·링크는 필요할 때만 추가한다.
- 기간순 타임라인과 유형/상태 필터는 활동이 누적된 뒤 제공한다. 필터는 현재 보이는
  결과 수와 초기화 동작을 보여 준다.

## 상태와 상호작용

| 상태 | 표시 방식 |
| --- | --- |
| 초안 | 아직 개인 기록이며 졸업·공식 이력 반영 대상이 아님을 표시한다. |
| 진행 중 | 시작일과 예상 종료/다음 증빙 행동을 보여 준다. |
| 학교 승인 확인 | 승인 결과가 필요한 이유와 학교 시스템 확인 경로를 표시한다. |
| 기록됨 | 개인 기록 저장 완료를 뜻하며, 승인 상태와 혼동하지 않는다. |

## 학교 제공 정보가 없을 때

- 학과 활동 인정 조건, 봉사 제출 안내, 교내 프로그램 안내가 없을 때 학생은 공지의
  링크·파일·조항과 적용 범위를 직접 남길 수 있다.
- 학생이 올린 안내는 `출처 정보 입력됨`으로만 보이며, 봉사 시간·사전교육·소감문·학교
  승인을 충족한 것으로 처리하지 않는다. 실제 활동은 학교 시스템에 제출·승인된 뒤
  UniversityPath에 기록하도록 안내한다.
- 출처가 없는 메모는 개인 활동 계획으로 저장하며 다른 학생과 공유하지 않는다. 공통
  상태와 수정·철회는
  [`../student-contributed-school-information-ux.md`](../student-contributed-school-information-ux.md)를 따른다.

## UI 검토 기준

- 한 활동에서 사용자의 역할과 팀/기관의 결과를 별도 필드로 적게 한다. AI는 서술을
  다듬을 수 있지만 사실·시간·승인 상태를 만들어 내지 않는다.
- 파일은 실제로 필요한 증빙에만 요구하고, 허용 형식·크기·민감 정보 주의를 선택 전에
  표시한다. 업로드 실패 시 파일명·입력 내용을 잃지 않는다.
- 외부 봉사 사이트로 이동할 때 새 창 이동임을 표시하고, 돌아온 후 자동 승인 처리하지
  않는다.
