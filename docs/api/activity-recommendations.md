# 활동 추천 API (2026-11-24)

`POST /api/v1/me/activity-recommendations`는 목표 직무를 준비하는 데 도움이 될 외부 활동의 **종류**를 추천한다. 대상은 해커톤, 공모전, 대외활동, 인턴·일경험, 봉사, 교육·훈련, 개인·팀 프로젝트다. 각 활동에 추천 이유와 검색어, 찾을 곳을 붙인다. 합격 가능성이나 지원 자격 판정이 아니며 항상 `official=false`다.

2026-11-24 수정: 처음에는 고용24 인턴 공고 목록(지역 선택 포함)도 보여 주었지만 뺐다. 고용24에는 대학생 인턴 공고가 매우 적고(소프트웨어·서울·경기에서 1건), 실제 공고 검색은 `공고 찾기`(job-recommendations)와 겹치기 때문이다. 인턴·일경험은 다른 활동처럼 종류로 추천하고 잡알리오·링커리어·고용24·온통청년 링크로 안내한다. 이 경로는 공고를 수집하지 않는다.

## 요청

```json
{
  "records": [{"kind": "experience", "record_id": "…", "expected_version": 1}],
  "academic_stage": "graduating",
  "external_processing_consent": true
}
```

- `records`: 저장된 기록 전체(공고 찾기와 같은 형식).
- `academic_stage`: `year1`~`year4`, `graduating`, `graduate`. 앱은 학업 프로필의 학년(`planning-profile.academic_stage`, 비어 있으면 입학연도로 계산)을 기본값으로 보낸다.
- 이 API는 결과를 저장하지 않는다. 앱이 끝난 결과를 [저장된 분석 결과](materials-and-results.md)에 `kind=activity`로 저장한다.
- 목표 직무는 저장된 `career-goal`을 쓴다. 없으면 `needs_user_input`과 `missing_fields: ["career_goal"]`을 돌려준다.

## 처리

1. 계정에 저장된 가장 최근 목표 직무 분석 결과(`analysis_results`, `kind=gap`)에서 '준비됨'이 아닌 요건을 최대 10개 꺼낸다. 이것이 부족 요건이다. 결과가 없으면 부족 요건 없이 목표 직무와 기록만으로 추천한다.
2. AI를 한 번 호출한다(최대 110초). 입력은 목표 직무, 부족 요건, 개인정보를 가린 기록, 학년, 사이트 목록이다.
   - 특정 행사·주최·날짜·링크는 만들지 않고, 활동의 종류만 3~6개 추천한다.
   - 경력 연수나 학위 요건은 활동으로 채울 수 없으므로 보완 요건으로 연결하지 않게 지시한다.
   - 서버가 응답을 검사한다.
     - 종류는 정해진 7가지만 받는다.
     - 보완 요건은 받은 부족 요건과 정확히 같은 글만 남긴다.
     - 찾을 곳은 서버 사이트 목록에 있고 종류가 맞는 것만 남기고, 없으면 그 종류의 기본 사이트로 채운다.
     - 검색어는 3개, 기간은 1~26주로 제한한다.

## 응답(완료)

`status`, `goal`, `gap_basis {analyzed_at, gaps}`, `recommendations[]`, `summary`, `sites {id: {name, url}}`(추천에 쓰인 사이트만), `model`, `generated_at`.

`recommendations[]`의 각 항목:

| 필드 | 내용 |
| --- | --- |
| `kind`, `kind_label` | 활동 종류와 한글 이름 |
| `title` | 할 일 |
| `reason` | 추천 이유 |
| `requirements` | 보완하는 부족 요건 |
| `keywords` | 검색어(최대 3개) |
| `sites` | 찾을 곳의 사이트 id |
| `deliverable` | 활동 후 기록할 결과 |
| `weeks` | 예상 기간(주) |

## 찾을 곳과 자동 수집

- 대외활동·공모전 사이트는 링크와 검색어만 준다.
  - 대상: 링커리어, 캠퍼스픽, 요즘것들, 씽굿, 콘테스트코리아, 위비티, 데이콘, Devpost.
  - 2026-11-24에 각 사이트 이용약관을 확인했다. 자동 접근·크롤링을 금지하거나, 사전 승낙 없는 복제·제3자 제공을 금지한다. 데이콘은 봇 차단 때문에 약관을 읽지 못했다.
  - 목록을 자동으로 가져오려면 서면 허락이나 제휴가 있어야 한다.
- 공식 API가 있는 공공 출처는 키를 발급받으면 실제 목록을 붙일 수 있다. 1365 자원봉사, 온통청년, 고용24 직업훈련, 잡알리오 체험형 인턴이 해당한다. 지금은 서버에 키가 없어 링크만 준다.
- 실제 채용·인턴 공고는 `공고 찾기`가 고용24에서 가져온다.

게이트웨이·웹 nginx는 이 경로에 180초를 허용한다.
