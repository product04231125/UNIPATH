## 프로젝트 반영 원칙

- 공통 졸업요건은 `GraduationRule`의 학교·입학연도·교육과정 적용 범위를 가진 규칙으로 모델링한다.
- 학과별 졸업인증 요건은 공통 규칙에 추가되는 별도 규칙으로 둔다.
- 보관 문서만으로 개인의 졸업 가능 여부를 확정하지 않는다. Rule Engine은 최신의 검증된 규칙 데이터와 학생의 학사정보를 사용한다.
