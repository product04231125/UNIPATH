# 학생 메뉴 UX 기준

이 문서는 학생 메뉴별 과업·UI·상태·직접 입력 경계를 정의한다. 공통 작업 공간, 접근성,
설정, 지원되지 않는 학교의 개인 기준은 [제품 UX 기준](product-ux.md)을 따른다. 아래는
설계 기준이며, 모든 항목이 현재 구현됐다는 뜻은 아니다.

## 홈

- 통계 대시보드보다 학생이 지금 할 일을 고르는 시작점이다. 졸업 가능 여부를 단정하거나
  AI 대화를 강요하지 않는다.
- 하나의 주 행동과 `학사 기준`, `이번 학기와 활동`, `공식 문서`, `성과와 진로`의 2×2
  카드를 둔다. 카드에는 목적·짧은 상태·명확한 목적지만 둔다.
- 학교 연동이 없으면 실패 수치 대신 `내 학교·학과 기준 설정`, 첫 수강/활동 기록 추가를
  제시한다. 개인 기준은 공식 졸업 판정이나 학교 연결 완료로 표현하지 않는다.

## 수강 관리

- 학교 수강 시스템의 확정 과목을 확인하고 현재/다음 학기 계획을 정리한다. 기본 목록은
  과목명, 구분, 학점, 상태, 출처로 구성한다.
- `이번 학기`, `수강 예정`, `이수 내역`을 구분한다. 교육과정 행렬은 목록과 분리하고,
  그룹 헤더·열·행이 함께 가로 스크롤한다.
- 지원되지 않는 학교는 과목명·코드·학기·학점·본인 분류를 직접 입력해 개인 교육과정과
  개인 기준 계산에 연결할 수 있다. 분류가 불명확하면 `확인 필요`이며 AI가 확정하지 않는다.

## 졸업 요건

- 학교·학과·입학연도·교육과정에 맞는 Rule Engine 판정을 투명하게 보여 준다. 입장 즉시
  적용 범위와 통합 상태를 보이며, `대학 공통`, `내 교육과정`, `학과 기준`은 하나씩 전환한다.
- 행은 요건, 현재 상태, 판정, 공식 근거 행동을 가진다. 공식 근거에는 문서명·페이지·
  적용 범위를 붙이고, 근거 부족에는 `근거 부족`을 명시한다.
- 공식 규칙이 없으면 `내 학교·학과 기준 설정`으로 개인 규칙을 만들 수 있다. 결과는
  개인 기준 계산이며 `학교 공식 졸업 판정 아님`을 항상 표시한다.

## 활동

- 교내 활동·봉사·동아리·공모전을 하나의 활동 단위로 기록한다. 제목, 기관/유형,
  기간/시간, 역할, 학교 승인 상태를 보여 준다.
- 외부 기록, 학교 제출, 학교 승인, UniversityPath 기록을 서로 다른 상태로 표현한다.
  외부 활동만으로 졸업 반영을 암시하지 않는다.
- 활동명·기관·기간/시간·역할·증빙을 직접 입력할 수 있고 개인 기준에는 쓸 수 있다.
  학교 승인값은 별도 상태로 남긴다.

## 경험

- 프로젝트·인턴·스터디·동아리 경험을 `상황/과제`, 역할, 실행, 결과·배운 점, 기간,
  증빙 순으로 사실 기반 기록한다. 팀 성과와 본인 기여를 섞지 않는다.
- AI는 누락된 역할·결과 질문과 이력서/STAR 초안을 제안할 수 있으나 확인 전 원본을
  저장하지 않는다. 긴 입력에는 임시저장과 이탈 경고를 제공한다.
- 학교 연동과 관계없이 직접 기록하며, 학교 안내는 실제 참여·성과 인증으로 바꾸지 않는다.

## 자격

- 자격증·어학·교육 이수는 명칭, 발급 기관, 취득/응시일, 유효 기간, 증빙 상태로 관리한다.
  상태는 `준비 중`, `취득`, `유효 기간 확인`, `만료`, `증빙 필요`로 제한한다.
- Q-Net 등 외부 기관은 준비 탐색·일정 안내로만 연결하고 자동 취득·등록하지 않는다.
- 학생은 발급 정보·유효기간·증빙을 직접 등록해 개인 자격/인증 기준에 연결할 수 있다.
  진위와 학교 필수 여부는 공식 정보와 분리해 표시한다.

## 포트폴리오·성과

- 프로젝트·논문·수상·발표를 제목, 유형, 한 문장 요약, 역할, 결과, 기간, 공개 범위,
  자료 상태로 기록한다. 파일은 설명을 보강하는 증빙이지 설명의 대체물이 아니다.
- 원본 기록과 지원 목적별 구성은 분리한다. AI의 요약·자기소개서 문장·순서 제안은 확인
  뒤에만 반영하며 공개 범위·파일 업로드·항목 추가를 자동 처리하지 않는다.
- 직접 입력 항목은 개인 포트폴리오와 AI 문맥에 쓰되 공개·수상·제출 완료·저작권을
  자동으로 확정하지 않는다.

## 설정

- 설정은 좌측 탐색 하단의 독립 본문 페이지다. 현재 목록의 필터·정렬·기록 추가는 해당
  작업 화면에 두며 설정으로 옮기지 않는다.
- `계정·정보` 안에는 `내 학교·학과 기준`을 둔다. 학교명·학과·입학연도·교육과정·개인
  규칙 세트·마지막 계산 시각을 보여 주고 개인 기준과 공식 기준을 구분한다.
- 개인 규칙·직접 입력 기록 연결은 수정·삭제할 수 있지만, 개인 기준이 공식 학교 값을
  덮어쓰지는 않는다.

## 공통 상태·참고

- 개인 기록은 `직접 입력`, `계획`, `학교 확인 필요`, `학교 기록 확인`처럼 출처와 영향을
  알 수 있는 텍스트 상태를 쓴다. 색만으로 구분하지 않는다.
- 모든 메뉴에서 입력 오류·저장 실패·AI 실패 시 작성 값과 다음 행동을 보존한다.
- 메뉴별 표·폼·파일·상태의 상세 접근성은 [제품 UX 기준](product-ux.md)의 QA 체크리스트를
  따른다. 메뉴 설계 참고로 [GOV.UK Task list](https://design-system.service.gov.uk/components/task-list/),
  [Carbon Data table](https://carbondesignsystem.com/components/data-table/usage/),
  [USWDS File input](https://designsystem.digital.gov/components/file-input/)을 사용한다.
