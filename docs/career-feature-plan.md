# 취업 중심 기능 계획

작성일: 2026-11-23. 결정: 이어진.

## 방향

UniversityPath AI는 학생의 취업을 돕는 서비스다. 그런데 지금까지 개발은 수강 관리·졸업 요건과
관리자 화면에 집중됐다. 그 기능들은 학교 포털과 겹치고, 활동·자격·자료·채용공고와 연결되지 않는다.
2026-11-23에 다음과 같이 정했다.

- 수강 관리·졸업 요건은 지우지 않고 `학사` 메뉴 아래로 내린다. 메뉴 순서는
  홈 · 채용공고 분석 · 활동 · 자격 · 자료 · 일정 · 학사다.
- 수업 기록은 활동·경험·자격·성과와 함께 직무 근거로 쓴다(채용 분석·공고 찾기).
- 차별점은 "내 대학생활 기록으로 목표 직무까지 얼마나 남았는지, 무엇을 해야 하는지 알려 주는 것"이다.

## 진행 중 (발표 전, 2026-11-23 ~ 11-28)

| 기능 | 내용 | 상태 |
| --- | --- | --- |
| A. 목표 직무 | 고용24 직종과 세부 검색어로 목표 직무를 저장한다(`GET/PUT /me/career-goal`). 홈 카드에 표시하고, 공고 찾기의 기본값으로 쓴다. | 구현 |
| B. 직무 갭 분석 | 목표 직무 공고 여러 건에서 자주 나오는 요건을 모은다. 요건마다 내 기록으로 충족하는지 근거와 함께 보여 준다([API](api/career-gap.md)). | 구현 |
| C. 준비 계획 | 부족한 요건마다 준비 행동(자격·활동·과제)을 제안하고 `일정에 추가`를 제공한다. | 구현 |
| D. 근거 있는 지원서 초안 | 공고와 문항에 맞춘 자기소개서 초안을 만든다. 문장마다 내 기록을 인용하고, 확인되지 않는 인용은 쓰지 않는다. | 예정 |

## 계획 예정

아래 기능은 진행 중인 A~D 다음 단계다. 데이터 출처와 이용 조건을 확인한 뒤 범위를 정한다.

### 1. 외부 활동 추천

- **목표:** 목표 직무와 부족한 요건에 맞는 외부 활동을 찾아 추천한다. 대상은 대외활동, 공모전, 봉사, 교육·훈련,
  청년 프로그램 등이다.
- **연결점:** B의 부족 요건과 C의 준비 행동, `활동` 메뉴의 기록·안내(현재 1365 봉사 링크만 있음).
- **필요한 것:**
  - 출처별 수집 방법. 공식 Open API를 우선한다. 후보는 1365 자원봉사포털, 고용24·HRD-Net 직업훈련,
    온통청년 청년정책 등이다.
  - 민간 공모전·대외활동 사이트는 이용약관과 robots.txt를 확인한 뒤에만 수집한다.
  - 추천 이유(어떤 요건과 연결되는지)와 원문 링크·마감일 표시.
  - 학생이 고른 활동을 `활동` 기록이나 `일정`에 넣는 동작.
- **고려 사항:** 출처·수집 시각을 표시한다. 마감된 활동은 뺀다. 광고성 게시물은 거른다. 개인 기록은 외부 검색어에 넣지 않는다.

### 2. 포트폴리오·자기소개서 작성과 문서 제공

- **목표:** 내 기록으로 포트폴리오와 자기소개서를 작성하고, 학생이 제출·공유할 수 있는 문서로 제공한다.
- **연결점:**
  - D의 근거 있는 지원서 초안.
  - 기존 지원 문서·포트폴리오 구성 저장(`application_documents`, `portfolio_compositions`).
  - 아직 메뉴에 연결되지 않은 초안 화면(`PortfolioDraftsPage`).
- **필요한 것:**
  - 포트폴리오 구성 생성: 프로젝트·성과 기록을 직무 요건 순서로 정리한다.
  - 문서 내보내기: DOCX·PDF, 필요하면 Google Docs. 어떤 형식을 지원할지는 확정이 필요하다.
  - 버전 관리: 공고별 사본을 만든다.
- **고려 사항:** 확인되지 않은 경력·성과를 만들어 넣지 않는다. 문서에는 학생이 확인한 내용만 남긴다.

### 3. 목표 직무 맞춤 자격증 추천

- **목표:** 목표 직무 공고에서 실제로 요구하거나 우대하는 자격증을 추천한다. 시험 일정과 응시 자격도 함께 안내한다.
- **연결점:**
  - B의 요건 집계(자격 요건이 몇 건의 공고에 나오는지).
  - C의 준비 행동.
  - `자격` 메뉴.
  - 자격증·발급기관 마스터(현재 스테이징 데이터 0건).
- **필요한 것:**
  - 국가자격 목록과 시험 일정 데이터. 후보는 공공데이터포털의 한국산업인력공단 국가자격 시험일정 Open API,
    Q-Net이다.
  - 민간자격은 민간자격정보서비스를 확인한다.
  - 이미 가진 자격은 추천에서 뺀다.
- **고려 사항:** 응시 자격 충족 여부를 판정하지 않는다. 공식 일정·자격은 원문 링크로 확인하게 한다.

### 4. 자격증 공부·활동 일정 관리

- **목표:** 추천받은 자격증 공부와 활동 준비를 일정으로 만들고 진행 상황을 관리한다.
- **연결점:** 기존 `일정`(개인 일정 서버 저장, 마감 분류), C의 `일정에 추가`.
- **필요한 것:**
  - 시험일 기준 역산 학습 계획(주차별 목표).
  - 접수·시험·발표 일정 가져오기(3번의 시험 일정 데이터).
  - 활동 마감 일정 가져오기(1번).
  - 진행 체크와 홈 요약.
  - 필요하면 알림.
- **고려 사항:** 자동으로 만든 일정은 학생이 확인한 뒤에 저장한다. 공식 일정이 바뀔 수 있음을 표시한다.
