# 학생 직접 구성 학교·학과 UX 기준

이 문서는 학교·학과가 UniversityPath를 지원하지 않아도 학생이 **본인 전용 학교·학과,
교육과정, 졸업 기준을 직접 구성**해 서비스 전체를 쓸 수 있게 하는 UX 기준이다. 단순한
개인 메모나 관리자에게 규정을 제보하는 흐름이 아니다.

## 1. 목표와 경계

- 학생이 학교명·학과·입학연도·교육과정을 설정하고, 수강·활동·경험·자격·성과를 직접
  입력해 자신의 학업 현황을 관리하게 한다.
- 학생이 구성한 개인 규칙 세트는 해당 학생에게만 적용하는 **개인 기준 계산**에 사용한다.
  다른 학생의 데이터·RAG 공식 근거·공유 규칙은 바꾸지 않는다.
- 공식 데이터가 있는 학교는 공식 Rule Engine 판정을 우선한다. 개인 규칙 계산은 학교가
  지원되지 않거나 공식 데이터가 비어 있을 때 쓰는 개인용 시뮬레이션이며, 학교의 최종
  졸업 판정을 대체하지 않는다.

## 2. 학생에게 보이는 모드와 상태

| 상태 | 의미 | 화면과 계산에 미치는 영향 |
| --- | --- | --- |
| `공식 학교 기준` | 관리자가 등록한 학교·학과·교육과정 규칙 | 공식 Rule Engine 판정과 공식 문서 RAG에 사용한다. |
| `개인 학교·학과 기준` | 지원되지 않는 학교용으로 학생이 구성한 본인 전용 규칙 세트 | 본인 화면에서 개인 기준 계산과 AI 문맥에만 사용한다. |
| `직접 입력 기록` | 학생이 직접 넣은 수강·활동·경험·자격·성과 | 개인 기준 계산의 입력값 또는 AI 문맥으로 사용한다. 학교 승인·공식 기록으로 자동 변경하지 않는다. |
| `학교 확인 필요` | 학생이 입력했지만 학교 원본 또는 승인이 필요한 값 | 개인 기준에는 사용 가능하나 공식 판정에는 쓰지 않는다. |

상태 칩은 색만으로 구분하지 않고 위 상태명을 그대로 표시한다. 개인 기준 계산 결과를
`공식 졸업 판정`처럼 표현하지 않는다.

## 3. 진입점과 기본 흐름

학교·학과가 지원되지 않았을 때 졸업 요건 화면과 초기 설정에서 **`내 학교·학과 기준
설정`**을 주 행동으로 제공한다. 이 행동은 개인 설정을 위한 정상 흐름이며, 숨은
관리자 요청이나 규정 제보가 아니다.

1. **내 적용 범위** — 학교명, 학과, 입학연도, 교육과정 명칭/연도를 입력한다.
2. **개인 규칙 세트** — 최소 총학점, 전공/교양 학점, 필수과목 수, 졸업인증 등 필요한
   항목을 하나씩 추가한다. 규칙은 이름, 비교 방식, 필요한 값, 현재 값을 가진다.
3. **내 기록 연결** — 수강·활동·경험·자격·성과 메뉴의 직접 입력을 해당 규칙의 현재
   값으로 확인하거나 수정한다. 학교 데이터가 나중에 연결돼도 개인 원본 기록은 보존한다.
4. **개인 기준 계산** — Rule Engine과 같은 결정론적 계산 UI로 충족·미충족·확인 필요를
   보여 주되, 상단에 `개인 기준 계산 · 학교 공식 판정 아님`을 항상 표시한다.

공식 학교 데이터가 뒤늦게 생기면 학생은 `공식 학교 기준`과 `개인 학교·학과 기준`을
나란히 볼 수 있다. 기본 졸업 판정은 공식 데이터가 있는 경우에만 공식 기준을 사용한다.

## 4. 메뉴별 직접 입력

| 메뉴 | 학생이 직접 구성하는 정보 | 개인 기준과의 관계 |
| --- | --- | --- |
| 수강 관리 | 과목명, 코드, 학기, 학점, 본인 분류 | 학점·필수과목 규칙의 입력으로 연결할 수 있다. |
| 활동 | 기관, 기간/시간, 역할, 학교 승인 상태 | 활동·봉사·졸업인증의 현재 값으로 쓰되 승인 여부는 별도 상태로 둔다. |
| 경험 | 프로젝트/인턴/동아리, 역할, 결과, 증빙 | 개인 진로·포트폴리오 문맥에 사용한다. |
| 자격 | 자격/성적/교육, 발급일, 유효기간, 증빙 | 자격·졸업인증 규칙의 입력으로 연결할 수 있다. |
| 포트폴리오·성과 | 프로젝트/논문/수상, 역할, 결과, 링크 | 개인 포트폴리오와 AI 문맥에 사용한다. |

AI는 개인 기준과 직접 입력을 바탕으로 누락 필드, 계산 방식, 정리 문장을 제안할 수 있다.
AI 제안은 학생이 `적용` 또는 `저장`을 확인하기 전까지 기준·기록을 바꾸지 않는다.

## 5. 문구와 오류 상태

권장 안내 문구는 다음과 같다.

> 학교가 아직 지원되지 않나요? 내 학교·학과 기준을 직접 설정해 개인 학업 현황을
> 계산할 수 있습니다. 이 결과는 학교 공식 졸업 판정과 별개입니다.

> 학교 공식 데이터가 연결되면 공식 기준으로 다시 확인할 수 있습니다. 직접 입력한
> 개인 기록은 지워지지 않습니다.

필수 범위·규칙 이름·비교 값이 빠졌을 때는 해당 필드에 오류 이유와 수정 방법을 표시하고,
이미 쓴 내용은 보존한다. 개인 기준이 없는 경우에도 학생의 기록 메뉴는 계속 사용할 수
있으며, 졸업 화면에서는 설정 시작 행동을 제공한다.

## 6. 구현 전 합의할 사항

- 개인 학교·학과 프로필, 교육과정, 규칙 세트, 개인 Rule Engine 감사의 데이터 모델과
  API 계약
- 개인 규칙의 비교 연산, 과목/활동/자격 기록 매핑, 규칙 버전과 계산 이력
- 개인 설정의 기기 간 동기화, 내보내기, 삭제와 개인정보 처리 기준
- 공식 학교 데이터가 등록될 때 개인 기준과 공식 기준을 전환·비교하는 정책

이 문서는 UX 정책이다. 실제 개인 규칙 API·파일 저장·개인 Rule Engine·RAG 필터 계약은
팀 합의와 권한·보안 설계 뒤에 별도로 확정한다.
